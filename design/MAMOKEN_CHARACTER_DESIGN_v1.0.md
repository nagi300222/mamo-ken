# マモ拳 キャラクター設計書 v1.0

- 状態: CHARACTER DESIGN CHECKPOINT
- 対象: 通常8キャラ＋アナザー1キャラ
- ロスター: 9キャラ・3×3
- 数値方針: 技の役割とキャラクター構造を確定し、ダメージ・フレーム・受付猶予はBAL／実機調整とする
- 既存3キャラの現行コマンド技は枠1〜3で維持する
- 各キャラは基本7技＋特殊能力1〜2個を持つ
- ギュイーンは全キャラ完全公平。キャラクター能力を一切乗せない
- ダークモグゾーの対人CharacterDefとCPU用BossRuleSetは完全分離する

## 2. 共通設計規則

### 2.1 見た目

キャラクターの識別は以下で行う。

1. 毛色と影色
2. 体格と構え
3. 装身具1点
4. 能力発動時の動き

実在種の毛色を基礎にしつつ、影色や毛先へ青紫・赤紫・灰緑などを加えて差別化する。

### 2.2 Reach Class

| Reach | 意味 |
|---:|---|
| 0 | 密着限定 |
| 1 | 通常位置へ届く |
| 2 | 浅いスウェーまで届く |
| 3 | 深いスウェーまで狩る |

Reach 3技には、長い発生・大きな後隙・低火力・条件限定・コンボ不可など、最低2つ以上の代償を持たせる。

### 2.3 技属性

- HIGH
- MID
- LOW
- GRAB

全キャラが4属性を最低1つずつ持つ。
属性配分はスタイルごとに偏らせる。

### 2.4 入力難度

| 難度 | 意味 |
|---|---|
| 初級 | 2方向入力。用途が明快 |
| 標準 | 状況判断または反応が必要 |
| 上級 | 3〜4方向入力、条件付き、派生判断が必要 |

受付猶予を極端に狭くして難しくすることは禁止する。

地面へ両手を叩きつけ、跳ね上がった相手へ渾身の掌底を打ち込む。

### 特殊能力1: フェイント

指定技のTelegraph中に←を入力して中断する。

- 攻撃判定なし
- 専用硬直
- 即つかみ不可
- 入力は通常コマンド履歴に積まない
- 同一フェイント連続使用の硬直増加はBAL候補

### 特殊能力2: ディレイ

指定技のTelegraph中に↓を入力し、発生を一度だけ遅らせる。

- 延長量は技ごとに固定
- 延長中の再フェイント不可
- 一度の技でフェイントとディレイを併用不可
- 入力は通常履歴に積まない

能力演出:
攻撃SEの冒頭だけが鳴って途切れ、毛と房飾りが一拍遅れて戻る。

### 咆哮: ずらし咆哮

発生前に明確な一拍を置く遅延型。
二拍目の予告は必ず見える形にする。

### 奥義: 百面本命打ち

複数の構えを高速で見せたあと、何のひねりもない全力頭突きを叩き込む。
演出中の三択は存在しない。

通常時は低威力・短い後隙。
返し窓中は発生または復帰が強化される。

### 奥義: 後の先・月断

# 4. ダークモグゾー アーケードボス仕様

## 4.1 出現条件

以下をすべて満たす。

- アーケードを最後までクリア
- コンティニュー未使用
- 難易度・使用キャラは問わない

通常エンディングへ入りかけたところで暗転し、EX戦へ移行する。

## 4.2 初遭遇後

一度でも出現させると、アーケードメニューへ「ダークモグゾーに挑戦」を追加する。
以後は通常戦をやり直さず再挑戦可能。

## 4.3 撃破報酬

- アーケードでダークモグゾー使用可能
- 専用エンディング
- プロフィール解放

オンライン、ローカル、CPU単発、トレーニングでは最初から使用可能。

## 4.4 ボス専用フェーズ

### Phase 1: 黒い基本

- モグゾーに近い均等な行動配分
- 地走り・昇撃・引き寄せ投げを中心に使う
- フェイントや不可視派生なし
- 技選択の精度で強さを見せる

### Phase 2: 裏拍

第2ラウンド開始またはHP条件で移行。

- 通常技からコマンド技への派生増加
- 同じ属性を連打しない
- ガード後の投げ選択増加
- スウェー狩りの重み増加
- Telegraph自体は短縮しない
- 小さなディレイを混ぜる

### Phase 3: 黒連鎖

最終ラウンドかつ低HPで、ニュートラル状態から1試合1回だけ発動。

## 4.5 BossRuleSet: 黒連鎖

黒連鎖ストックを1個得る。

次に出したコマンド技がヒットまたはガードされた場合、別の指定コマンド技へ1回だけ派生できる。

制限:
- 同技派生不可
- 2回以上連鎖不可
- 強いダメージ補正
- 空振り・回避でもストック消費
- 空振り後は大きな後隙
- ガード後派生には割り込み可能な隙間
- 奥義へ直接派生不可
- ギュイーン中無効
- KOをまたいで持ち越さない

## 4.6 ボスAIで禁止するもの

- 未公開入力読み
- ボタン押下前の段属性把握
- 0F反応
- 入力バッファ参照
- ギュイーン性能差
- 不可視ダメージ補正
- 判別不能なTelegraph
- 対人CharacterDefへのBossRuleSet混入
