# マモ拳奥義ムービー｜約10秒・全9キャラ演出指示（本人の追加確定要件）

<date>2026-11-22</date>｜制作者：依頼内容＝ナギ本人、制作上の補足＝ミオ。関連：[Claude制作 Issue #177](https://github.com/nagi300222/mamo-ken/issues/177)・[Codex統合 Issue #178](https://github.com/nagi300222/mamo-ken/issues/178)・[PR #180](https://github.com/nagi300222/mamo-ken/pull/180)。

## 0. 今回の最優先指示

**本人の追加指定**：「共通の設計は、10秒程度の構成、相手のやられモーション、キャラを魅せるカメラワーク」。以下の9体別演出は**ナギ本人が直接指定した構成・モチーフ**。以前の`4〜6秒`・`4〜7カット`・共通`3ビートズーム`は**本件で上書き**。試作を渡して都度試遊依頼する方式も不要。

- 各奥義の通常版は**合計約10秒**、編集上の目安9〜11秒（命中成立直後から最後の決めポーズまで）。時間を稼ぐために静止画像を長く持たせない。
- **必ず相手のやられモーションが重要な役者**：打ち上がり・吹き飛び・踏みとどまり・失神・投げられ/回転・崩れる・爆発から転ぶなど。攻撃側だけが動いて相手が静止するムービーを不可。
- **キャラを魅せる本格カメラ**：低い足元アングル、手/顔のクローズアップ、斜め追走、縦方向の追尾、相手越しショット、オービット、ドリーイン、肩越し、後ろ姿、広角の全景、カメラ速度の緩急をキャラごとに選ぶ。単純なズーム/パンで済ませない。
- **各キャラ専用の場面設計**。6〜10ショット程度を初期目安として、カット数は作品ごとに調整可。全9体で同じテンポ・カット順・ヒット数に揃えない。
- 「命中したら映画」：`ultimate_hit` が確定した場合だけ開始。空振り/ガード/無効化なら入らず、戦闘は通常進行。ムービー中はBattle、CPU、タイマー、HP/ゲージの数値変化を停止。ムービー中の連撃は**視覚的演技**で、ダメージを二重適用しない。終了/スキップは既存のゲームに戻り、KOは映画の後に結果。
- 音楽、打撃音、攻撃のヒットストップ、エフェクトをモーションとカメラの**同一タイムライン**で同期。長めのヒットストップは原則**映画側の演出的停止**とし、対戦用の発生・硬直・ダメージ値を無断変更しない。
- 雪山、巨岩、暗夜などは**ムービー内の専用ステージ表現**とする。原作世界の正式設定を捏造したり通常対戦ステージを勝手に差し替えたりしない。
- 参考技・他作品の演出は方向性の説明。**他社キャラクターの正確なポーズ・カット割り・技映像を丸ごとトレースせず、マモ拳の独自アクションとして制作する**。

## 1. 奥義9本の本人指定＋演出の読み解き

### モグゾー｜大地烈掌（現行名称。名前の変更は別提案）

**本人指定**：ベースは「真・昇龍拳」。アッパーから始動し、**追い打ちのアッパーで高く打ち上げる**。エフェクトはド派手。**ヒットストップ長め**。

演出ビート（秒位置はClaudeが調整）：
1. 低い拳・踏み込みのアップから最初のアッパー。拳に乗るカメラで顎を跳ね上げ、相手の首・上体が反る瞬間を見せる。
2. 最初の重い衝撃は少し長い静止/スロー。地面・空気が拳に連動してひび割れるほどの迫力（地割れはシネマティック素材）。
3. 相手が宙で姿勢を失ったところへ**追い打ちの2段目アッパー**。カメラは接近→真下からの縦追いで高度を強調し、相手が頭上へ飛ぶ。
4. 頂点で大きなエネルギー/衝撃の軌道と長めのヒットストップ。地上側へ戻って拳を見せる決め構図、相手の落下と結果への接続。

**必須**：2回のアッパーが違う構え/重さを持つ。相手の打上げ軌道が連続し、同じアニメを再生するだけにしない。

### ピスケ｜音速連咆

**本人指定**：キャミィをベースにした**蹴り突撃の反復**、最後は**サマーソルト**で締める。**速さ最優先**。

1. 急激に低い姿勢から踏み切り、画面の奥行きを駆け抜ける初回蹴り。被弾側の体が横へ持っていかれる。
2. 別角度へ切り返して再突撃。横追い/相手越し/低いドリーを鋭く切り替え、蹴る足の方向が毎回判別できるようにする。
3. 複数回の高速突撃で相手の体が前後左右に弾かれ、脚の運動が目で追える程度の**意図的な緩急**を一瞬入れる。
4. 最後は**回転からのサマーソルト**で上へ弾き、空中の相手とピスケを大きく見せて着地。速さと軽さを失わない。

**必須**：横移動の繰返しだけにしない。最終サマーソルトのシルエットが明確。カメラが早くても位置関係が崩れない。

### ゴダン｜山崩し

**本人指定**：**渾身の三連撃**。武道のような構え→足元の強い踏み込み→**一撃ずつの重さ**。最後の一撃で**背後の岩ごと破壊**。

1. ゴダンの武道的な静かな構え・掌・視線。足元の接地と重心の移動を低いアングルで見せる。
2. **第一撃**：全身を使った打撃。短い静止・大きな衝撃で相手が一歩押される。
3. **第二撃**：体の向きを変えた違う軌道の打撃。空気を押し潰すような迫力、相手が後方へ弾き飛ばされる。
4. **第三撃**：深い踏み込みから最大の打撃。相手の後ろにある**巨大な岩壁ごと破壊**。破片・粉塵・衝撃波の広角ショット→ゴダンの重い残心。

**必須**：三撃は強さ・姿勢・重さを段階的に上げる。相手/岩破壊が別々のシーンでなく連続因果に見えること。

### ハクマ｜白峰不動掌

**本人指定**：**雪山**。張り手で相手を押し出していき、最後は**背負い投げで反対方向へ**。とにかく重さを表現。

1. 雪山の寒気と足元の積雪を見せる。ハクマの重い立ち姿と大きな両掌を正面の低い位置から撮る。
2. 一発ごとの**重い張り手**で相手が雪の上を押し戻される。相手の足が抵抗し、雪煙が積もって舞う。
3. ハクマが距離を詰め、相手の重心を一気に懐へ入れる。肩越しから低い視点に切り替え、投げる前に一瞬の力みを見せる。
4. **背負い投げ**で攻撃方向が反転。カメラを相手の回転に合わせて回し、画面の反対側へ豪快に投げ飛ばす。着雪の重い衝撃と白い飛沫で締める。

**必須**：単純な突っ張り→押し出しで終わらず、**最後の投げで画面の力学・方向を反転**させる。

### チルカ｜百面本命打ち

**本人指定**：分身で撹乱し、**多方向からの連撃**、**紫の爪痕と毒々しさ**。その一方で**顔アップなど可愛らしさ**も見せる。

1. チルカの**可愛い表情の顔アップ**。瞬き・首かしげ・小悪魔的な笑みで油断を誘う。
2. 紫の分身が左右・背後に分かれ、相手がどれを見ればいいか分からず視線を泳がせる。カメラも分身の間をすり抜ける。
3. 上下左右の異なる角度から分身と本体が連撃。相手の体が各方向へ向き直らされ、紫の爪痕が空間に重なる。毒々しい紫の気配を増す。
4. 本物のチルカがカメラの予想外の方向から現れる。可愛さから一瞬で**本命の鋭い一撃**へ切り替え、爪痕と幻影が最後に一つへ収束。

**必須**：分身はゲーム用の別判定キャラではなく映画上の演技。紫の残像だけでなく複数の3D姿が動き、相手の視線/被弾が多方向に反応すること。

### タキマル｜天地落とし

**本人指定**：**最初に前方へ投げ**、**煽るように相手を見下ろす**。再び拾い上げて**ジャイアントスイング**。荒々しさ。

1. 掴みから**前へ荒々しく投げる**。低めの相手目線で地面に投げられる痛みと距離を見せる。
2. 倒れた相手をタキマルが一歩近づき、**煽るように見下ろす**。相手から見上げるカメラとタキマルの目線を使う。
3. 相手を再度つかみ上げ、体格差と重心移動を誇張して**ジャイアントスイング**へ。カメラは腰の回転に合わせて360度追う・相手視点などを組み合わせる。
4. スイングの最高速度から一気に放り投げ、荒々しく落下・激突。タキマルは余裕の姿勢、相手はダウン。

**必須**：ただ回転するだけでなく、掴み・足運び・相手の身体の遠心力・放り投げの方向が因果的に見える。

### ヨミカゲ｜後の先・月断

**本人指定**：**闇夜に紛れて相手が見失う**。背後からの一閃、うずくまる相手へ**追撃の一閃でダウン**。**黒い閃光**、必殺の鋭さを演出。

1. 闇夜に照明が落ち、相手が周囲を探してヨミカゲを見失う。相手側の視線・息遣いを接写。
2. 一瞬の暗転と気配。相手の**背後**に静かに出現するヨミカゲを肩越し/背中側から見せる。
3. **第一の黒い一閃**。短い軌跡と相手の身体が折れて**うずくまる反応**。斬撃の「静」と短いインパクトを優先。
4. うずくまる相手の横顔、ヨミカゲの表情。カメラが一気に回り込んだ直後、**追撃の第二の一閃**でダウン。黒い閃光だけ残る決め構図。

**必須**：二つの一閃が違う意味を持つ（崩す→とどめ）。暗いだけで何が起きたか見えなくならない。

### バレット｜超圧縮・弾丸頭突き（現行名称は要整合レビュー）

**本人指定**：**尻尾主体の重い打撃**を浴びせ、**爆発する木の実**を投げる。最後は**振り向き、背後で相手が爆発**する。

1. 長い尻尾の予備動作・先端を目立たせる低いカメラ位置から、重い尻尾打撃。相手は横に押し出される。
2. 尻尾を異なる角度で振り、連続の重量打撃。相手の反動を見せ、足元と地面に衝撃を伝える。
3. 少し間を置き、**爆発する木の実**を相手へ放つ。木の実の接近と相手の気付き・遅い反応を撮る。
4. バレットは**背を向けて振り向きポーズ**を完成させる。その**背後で相手が大爆発**し、爆炎はバレットをシルエットにする。最後は落ち着いた決め顔/尾。

**必須**：木の実の放出・到達・爆発の因果と、尻尾が主役であること。現行奥義名の「頭突き」と新しい指定が合わないため、Claudeは**改名案を提示**し、実装名の変更はユーザー承認待ちとする。

### ダークモグゾー｜暗連・黒天烈掌

**本人指定**：「瞬獄殺」のようなイメージ。**闇のオーラで連撃し、最後に重い一撃**。**ラストは後ろ姿**。

1. 闇の気配が広がり、ダークモグゾーが相手の間合いに侵入。低く短い構え・目線を見せる。
2. 闇のオーラが相手を包み、明暗の間で**高速の連撃**。毎回少し違う拳/体の向きと被弾側の反応を短いカットで刻む。真っ暗な連続フラッシュのみにはしない。
3. 間が生まれ、ダークモグゾーの拳/肩が一瞬重く沈む。今までの速度と逆の**重い最後の一撃**が決まる。
4. 相手が倒れ、奥行きに残る黒紫の残光。**ダークモグゾーの後ろ姿**で締める。既存ゲームや他作品のロゴ/文字演出の忠実な再現は避ける。

**必須**：乱打の速さ→静止→重い決着という緩急と背面での終幕。本人の参考技をそのまま模写せず独自の構図を作る。
