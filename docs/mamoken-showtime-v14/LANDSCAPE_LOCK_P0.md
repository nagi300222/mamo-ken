# P0 iPhoneの画面回転ロック中もゲーム画面は常時横持ち

本人の実機フィードバック：「ゲーム画面を回転しなくても横持ち限定にしてほしい」。縦画面での「端末を回転してね」表示をやめ、iOSの本体回転ロックONでもページ内のゲーム全体をCSSで90°時計回りに回す。

## 実装
- `#app` をportraitタッチ環境だけ `rotate(90deg)`で表示し、ゲーム内の横画面レール/9体選択/6ボタン/全画面ムービーを同じ方向に保つ。実端末が横向きになったらCSS回転を解除する。
- ブラウザのネイティブURLバー・端末OSの回転状態は変更しない。Safariの`screen.orientation.lock()`に依存せず、ユーザーのiOS画面回転ロックを上書きしようとしない。
- ジョイスティックは逆行列で物理ポインタ座標からゲームのX/Yへ変換する。ボタン/ステップはDOMの通常のPointer Eventsを使い、2本指の同時タッチの意味を保つ。
- `#cinematic-layer` は `#app` 内なのでゲームごと回転する。ブラウザtop-layerのpopoversは特殊ケースとして再回転する。
- ブラウザバーの伸縮/実端末回転/タブ復帰時に寸法を再計算、切替え時の旧スティック入力を消去。
