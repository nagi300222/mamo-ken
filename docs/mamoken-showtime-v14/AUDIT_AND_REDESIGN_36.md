# マモ拳 v14｜27必殺＋9奥義の実映像監査と再設計カタログ

作成: 2026-11-22 / Claude（ヨル）/ [Issue #177](https://github.com/nagi300222/mamo-ken/issues/177)

この文書は「実際に見たもの」と「提案」を分けて書く。採点と再設計案はどちらもヨルの判断で、ナギの採否は未確定。

## 1. 監査のやり方（実際に行ったこと）

- 実ゲーム `exp/fable-3d/dojo/` を Chromium（WebGL・SwiftShader）で開き、**スマホ横画面 852×393 の対戦カメラのまま**、9体 × 4技 = 36技を1戦闘フレームずつ撮影した。撮影は `exp/fable-3d/cinematic/v14/tools/capture_specials.mjs`。ゲームのソースは書き換えず、CPU を無入力にする差し替えだけを通信レベルで行った。
- 相手はピスケ固定。打撃・突進・対空は当たる間合い、飛び道具は 1.25m。奥義は命中させ、現行 v13 のムービーも最後まで撮った。
- 36技ぶんのコンタクトシートは `exp/fable-3d/cinematic/v14/evidence/audit_before/<id>.jpg`（各キャラ 4段 × 8コマ）。採点はこのシートと連番を目で見て付けた。
- 再生されたクリップ名は撮影ログ `evidence/audit_before/capture_log.json` に残した（`models.js` の `chooseClip` は `command_map` を最優先するので、`balance.js` の `anim` と違うクリップが出ている技がある）。

見ていないもの: iPhone 実機、60fps の体感、音。採点は静止コマと低速再生での見え方に基づく。

## 2. 全体の所見

1. **対戦画面では体が小さい。** 852×393 でキャラの身長は約 70px。腕を少し前へ出す程度の差は読めない。読めるのは「体の高さが変わる」「体が大きく傾く」「手足が体の外へ長く出る」「宙に浮く」の4つ。
2. **s1 が5体でほぼ同じ形。** モグゾー・ピスケ・ヨミカゲ・ダークモグゾー・ハクマの s1 は「片手か両手を前へ出す」で、違いは弾の色だけ。CLAUDE.md の「色や大きさだけで区別しない」に最も反している。
3. **対空が2系統しかない。** 「跳んで片手アッパー」（モグゾー・ゴダン・ヨミカゲ・ダークモグゾー）と「蹴り上げ」（ピスケ・チルカ。同じ関数 `cmd_flipkick`）。
4. **技名と動きが合っていない技が3つ。** モグゾー s3「地走り」（実際はその場のフック→裏拳）、ピスケ奥義「音速連咆」（実際は連続蹴り。咆哮の要素なし）、バレット奥義「超圧縮・弾丸頭突き」（対戦画面では尻尾を上げる動きが主で、頭突きに見えない）。
5. **奥義ムービー（v13）は9体とも同じ進行。** 背中の寄り → 横の2ショット（ひし形の光）→ 攻撃側の寄り → 相手の寄り（円のワイプ）→ 2ショット。相手は構えたまま動かず、攻撃側も構えに戻っている。違うのは背景色と字幕だけ。例外はタキマル（投げの流れで相手が倒れている）。
6. **タキマルの s3 と奥義が同じクリップ（`throw_hit`）。** 奥義が必殺と見分けられない。
7. **良いもの。** バレットの尻尾3技（部位が大きく、他の誰にも流用できない）、タキマル s1（両腕を上げてから床を打つ。予備動作が大きい）、タキマル s3（相手が実際に投げられる）。

### 第一弾の奥義ムービー（命中後のみ・約10秒版）

構成は [ULTIMATE_10S_DIRECTION.md](ULTIMATE_10S_DIRECTION.md)（ナギ本人の指定）に従った。秒位置・カメラ・相手の芝居の細部はヨルの判断。

| キャラ | カット数 / 秒 | 流れ | カメラの考え方 | 相手の芝居 | 止め（ヒットストップ） |

| モグゾー「大地烈掌」 | 8 / 10.0 | 低い拳 → 足を地に付けたままの一段目 → 浮いた相手の下で深く巻く → 回転跳びの二段目 → 縦の上昇 → 頂点の光柱 → 着地と墜落 → 拳を空へ | 「縦」。拳に乗る寄り → 真下からのあおり → 上昇に並走して半周 → 遠景 → 地面 | あごを跳ね上げられ首と上体が反る → 力が抜けて浮く → 拳の上で折れ曲がる → 大の字で打ち上がる → 落ちて跳ねる | 0.5 / 0.4 / 0.7 秒 |

本人指定の「必須」との対応:
- モグゾー「2回のアッパーが違う構え／重さ」: 一段目は足を地に付けた伸び上がり、二段目は右へ巻いた深い沈みからの回転跳び。相手の軌道は「つま先が浮く → ゆっくり浮く → 一気に上昇」で連続。
- ゴダン「三撃は段階的に上げる／岩破壊が連続因果」: 軌道は直線・横・押し込み、止めは 0.4 → 0.45 → 0.7 秒。二撃目で相手が岩壁に張り付き、三撃目の止めが解ける瞬間に同じ岩壁が砕ける。
- チルカ「複数の3D姿が動き、相手が多方向に反応」: 分身は攻撃側 GLB の複製 4 体で、それぞれ別の必殺クリップ（影引き爪・頭上からの爪・だまし突き・跳ね爪）で当てる。爪痕は空間に残り、本命の直前に一点へ集まる。

動画: `exp/fable-3d/cinematic/v14/evidence/movies/`（相手ピスケの通常版、体格の違う相手・左右反転版、旧 v13 との上下比較）。絵コンテの正本: `exp/fable-3d/cinematic/v14/storyboard/<id>.mjs`。

技名について（提案・未採用）: モグゾーの奥義は本人指定で掌打ちから拳の二段アッパーになった。「大地烈**掌**」のままだと動きと合わないので、改名するなら「大地昇烈拳」「大地双昇」などが候補。現行名のまま制作している。
