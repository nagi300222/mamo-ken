# マモ拳 v14｜27必殺＋9奥義の実映像監査と再設計カタログ

作成: 2026-11-22 / Claude（ヨル）/ [Issue #177](https://github.com/nagi300222/mamo-ken/issues/177)

この文書は「実際に見たもの」と「提案」を分けて書く。採点と再設計案はどちらもヨルの判断で、ナギの採否は未確定。

## 1. 監査のやり方（実際に行ったこと）

- 実ゲーム `exp/fable-3d/dojo/` を Chromium（WebGL・SwiftShader）で開き、**スマホ横画面 852×393 の対戦カメラのまま**、9体 × 4技 = 36技を1戦闘フレームずつ撮影した。撮影は `exp/fable-3d/cinematic/v14/tools/capture_specials.mjs`。ゲームのソースは書き換えず、CPU を無入力にする差し替えだけを通信レベルで行った。
- 相手はピスケ固定。打撃・突進・対空は当たる間合い、飛び道具は 1.25m。奥義は命中させ、現行 v13 のムービーも最後まで撮った。
- 36技ぶんのコンタクトシートは `exp/fable-3d/cinematic/v14/evidence/audit_before/<id>.jpg`（各キャラ 4段 × 8コマ）。採点はこのシートと連番を目で見て付けた。
- 再生されたクリップ名は撮影ログ `evidence/audit_before/capture_log.json` に残した（`models.js` の `chooseClip` は `command_map` を最優先するので、`balance.js` の `anim` と違うクリップが出ている技がある）。

見ていないもの: iPhone 実機、60fps の体感、音。採点は静止コマと低速再生での見え方に基づく。

## 2. 全体の所見

1. **対戦画面では体が小さい。** 852×393 でキャラの身長は約 70px。腕を少し前へ出す程度の差は読めない。読めるのは「体の高さが変わる」「体が大きく傾く」「手足が体の外へ長く出る」「宙に浮く」の4つ。
2. **s1 が5体でほぼ同じ形。** モグゾー・ピスケ・ヨミカゲ・ダークモグゾー・ハクマの s1 は「片手か両手を前へ出す」で、違いは弾の色だけ。CLAUDE.md の「色や大きさだけで区別しない」に最も反している。
3. **対空が2系統しかない。** 「跳んで片手アッパー」（モグゾー・ゴダン・ヨミカゲ・ダークモグゾー）と「蹴り上げ」（ピスケ・チルカ。同じ関数 `cmd_flipkick`）。
4. **技名と動きが合っていない技が3つ。** モグゾー s3「地走り」（実際はその場のフック→裏拳）、ピスケ奥義「音速連咆」（実際は連続蹴り。咆哮の要素なし）、バレット奥義「超圧縮・弾丸頭突き」（対戦画面では尻尾を上げる動きが主で、頭突きに見えない）。
5. **奥義ムービー（v13）は9体とも同じ進行。** 背中の寄り → 横の2ショット（ひし形の光）→ 攻撃側の寄り → 相手の寄り（円のワイプ）→ 2ショット。相手は構えたまま動かず、攻撃側も構えに戻っている。違うのは背景色と字幕だけ。例外はタキマル（投げの流れで相手が倒れている）。
6. **タキマルの s3 と奥義が同じクリップ（`throw_hit`）。** 奥義が必殺と見分けられない。
7. **良いもの。** バレットの尻尾3技（部位が大きく、他の誰にも流用できない）、タキマル s1（両腕を上げてから床を打つ。予備動作が大きい）、タキマル s3（相手が実際に投げられる）。

### 第一弾の奥義ムービー（命中後のみ・約10秒版）

構成は [ULTIMATE_10S_DIRECTION.md](ULTIMATE_10S_DIRECTION.md)（ナギ本人の指定）に従った。秒位置・カメラ・相手の芝居の細部はヨルの判断。
先に作った 5.6〜5.8 秒版（掌底→空中叩き落とし／差し上げ→岩砕き／偽の一撃が空振り）は、この指定を受けて破棄した。

| キャラ | カット数 / 秒 | 流れ | カメラの考え方 | 相手の芝居 | 止め（ヒットストップ） |
|---|---|---|---|---|---|
| モグゾー「大地烈掌」 | 8 / 10.0 | 低い拳 → 足を地に付けたままの一段目 → 浮いた相手の下で深く巻く → 回転跳びの二段目 → 縦の上昇 → 頂点の光柱 → 着地と墜落 → 拳を空へ | 「縦」。拳に乗る寄り → 真下からのあおり → 上昇に並走して半周 → 遠景 → 地面 | あごを跳ね上げられ首と上体が反る → 力が抜けて浮く → 拳の上で折れ曲がる → 大の字で打ち上がる → 落ちて跳ねる | 0.5 / 0.4 / 0.7 秒 |
| ゴダン「山崩し」 | 8 / 10.2 | 構え → 震脚 → 右正拳 → 逆へ巻いての左裏拳 → 歩いて詰める → 両の掌 → 岩壁ごと崩壊 → 一礼 | 「重さ」。足元→掌の縦移動 → 地面 → 真横 → 相手の肩越し → 後退ドリー → 当たりで一気に寄る → 壁の向こうの高い広角 | 震脚で跳ねる → 腹を折って足を滑らせる → 横殴りで岩壁に張り付く → ずり落ちて座り込む → 両手をかざす → 押し潰され壁ごと吹き飛ぶ | 0.4 / 0.45 / 0.7 秒（段階的に長く） |
| チルカ「百面本命打ち」 | 9 / 10.0 | 可愛い顔 → 分身 4 体に分かれる → 輪をすり抜ける → 四方向の連撃と残る爪痕 → カメラの前に本体が顔を出す → 爪痕が集まって本命 → 爪をなめる | 「可愛い ⇄ 毒」。正面の顔 → 輪の外から内へ → あおり／俯瞰／横の振り → ゆっくりした寄りの手前に本体 → 背後の地面 | 首をかしげる → 目で追う → 横・上・下・突き上げで毎回別の向きへ崩れる → 毒でふらつく → 背中を打たれて飛ぶ | 0.18 ×4（軽い） / 0.6 秒 |

本人指定の「必須」との対応:
- モグゾー「2回のアッパーが違う構え／重さ」: 一段目は足を地に付けた伸び上がり、二段目は右へ巻いた深い沈みからの回転跳び。相手の軌道は「つま先が浮く → ゆっくり浮く → 一気に上昇」で連続。
- ゴダン「三撃は段階的に上げる／岩破壊が連続因果」: 軌道は直線・横・押し込み、止めは 0.4 → 0.45 → 0.7 秒。二撃目で相手が岩壁に張り付き、三撃目の止めが解ける瞬間に同じ岩壁が砕ける。
- チルカ「複数の3D姿が動き、相手が多方向に反応」: 分身は攻撃側 GLB の複製 4 体で、それぞれ別の必殺クリップ（影引き爪・頭上からの爪・だまし突き・跳ね爪）で当てる。爪痕は空間に残り、本命の直前に一点へ集まる。

動画: `exp/fable-3d/cinematic/v14/evidence/movies/`（相手ピスケの通常版、体格の違う相手・左右反転版、旧 v13 との上下比較）。絵コンテの正本: `exp/fable-3d/cinematic/v14/storyboard/<id>.mjs`。

技名について（提案・未採用）: モグゾーの奥義は本人指定で掌打ちから拳の二段アッパーになった。「大地烈**掌**」のままだと動きと合わないので、改名するなら「大地昇烈拳」「大地双昇」などが候補。現行名のまま制作している。

## 5. 残り6体の再設計案（未制作・案のみ）

第一弾の統合品質確認が済むまで制作しない。性能変更が要りそうな案には印を付けた。

### ピスケ（高速・チェイス / 風 / 脚）
- **s1 風の気弾 → 刷新**: 手ではなく蹴りで出す。軸足で半回転し、回し蹴りの足先から風の刃。構えから一度背中が見える。
- **s2 空牙蹴り → 改良**: 蹴り足を真上まで上げて体を一直線に（縦の開脚）。頂点で一瞬止める。
- **s3 連脚 → 改良**: 二連を三連に見せる（中→上→後ろ回し）。蹴るたびに軸足を踏み替えて前進がクリップに見える。
- **奥義 音速連咆 → 刷新**: 名前に合わせて「咆哮で止めてから脚」。**ムービー案（5カット）**: 咆哮の衝撃波で相手が浮く正面 → 相手の周りを残像を残して蹴り抜ける真横の高速ドリー（1往復ごとにカメラが反対側へ切り替わる）→ 背面からの追い → 真上からの俯瞰で蹴りの軌跡が星形に残る → 逆立ちの蹴り上げで止め。相手は一撃ごとに逆方向へ弾かれる。

### ハクマ（守勢・鉄壁 / 雪）
- **s1 雪壁掌 → 刷新**: 押し出すのではなく「受け止める」。半身で片手を大きく前に立て、もう片手を引いて掌底を重ねる二段。体は下がらない。
- **s2 白峰対空 → 改良**: 両手を合わせて頭上へ突き上げ、つま先立ちで体を一本の柱にする。
- **s3 連続突っ張り → 改良**: 一発ごとに足を一歩。腕は肩ごと出す（相撲の突っ張り）。最後の一発だけ両手。
- **奥義 白峰不動掌 → 刷新**: s1 と同じに見える問題を解く。**ムービー案（4カット。あえて少なく、動かないカメラ）**: 相手の連打を胸で受けて一歩も動かない正面の固定（相手だけが動く）→ 足元の寄り（雪が舞い、足が床にめり込む）→ 相手の背後からの望遠で、掌がゆっくり胸に置かれる → 遅れて相手だけが画面奥へ吹き飛ぶ引き。カメラが動かないことが個性。

### タキマル（投げ・接近 / 組み）
- **s1 大地走り → 維持**（予備動作が大きく、今も読める）。
- **s2 抱え上げ → 改良**: すくい上げた腕が頭上で止まる時間を伸ばす。
- **s3 抱え込み → 維持**。
- **奥義 天地落とし → 刷新**: s3 と別クリップにする。**ムービー案（6カット）**: 抱え込む腕の寄り → 相手を抱えたまま跳ぶ足元 → カメラごと上下が逆さになる（相手の視点。空と地面が入れ替わる）→ 落下を真横から並走 → 地面からの見上げで着弾 → 起き上がって帯を締め直す。相手は抱えられてもがき、逆さで手足が伸びる。

### ヨミカゲ（反撃・見切り / 月）
- **s1 残月の波 → 刷新**: 腕を前へ出すのでなく、頭上から足元まで腕で半月を描く。体は横向きのまま動かない。
- **s2 昇り肘 → 改良**: 跳ばずに一歩入って肘。肘を出す腕と逆の手で相手の腕を払う形。
- **s3 受け返し → 刷新**: 空振りでも「待っている」と分かる構えが要る。片手を下げて目を閉じ、重心を後ろ足へ（無防備に見せる）。**性能変更の検討あり**: 受付の見た目を長く取りたいので、受付開始を見た目上 2F 早めたい。数値変更は別提案。
- **奥義 後の先・月断 → 刷新**: **ムービー案（5カット）**: 無音・画面が暗くなり、相手の攻撃だけがスローで来る正面 → ヨミカゲの目の寄り（開く）→ 一歩で相手の背後へ抜ける真横の一枚絵（二人の位置が入れ替わる）→ 相手の背中越しに遅れて月形の光が走る → 背中合わせの残心、相手が崩れる。動きは一歩と一閃だけ。

### バレット（長射程・長尾）
- **s1 木の実弾 → 維持**。
- **s2 尾跳ね → 改良**: 尻尾の先が頭上で止まる一瞬を作る。
- **s3 尾薙ぎ → 維持**（6尾ボーンと `tail_tip_path` は現行のまま保持）。
- **奥義 超圧縮・弾丸頭突き → 刷新**: 名前どおり頭突きにする。尻尾をばねのように巻いて体を縮め、頭から飛ぶ。**ムービー案（5カット）**: 尻尾が巻かれていく寄り（ばねの音）→ 体が縮むのを真正面から（照準のように相手が中央）→ 発射を真横の超望遠で、背景が流れる → 相手の背後から、頭が腹に刺さる → 反動で宙返りして尻尾で着地。**性能変更の検討あり**: 間合い 0.90 は頭突きの見た目より長いので、突進の移動量をクリップに持たせるかはゲーム側と相談。

### ダークモグゾー（高速連携・低耐久 / 闇）
モグゾーの色違いに見せないことが最優先。モグゾーは「地面・掌・正面」なので、こちらは「空中・拳・背後」に寄せる。
- **s1 黒い地走波 → 刷新**: 地面を打たない。逆手で地面を引き裂くように腕を下から上へ振り上げ、体が反る。
- **s2 逆昇撃 → 改良**: 左のアッパーを、背を向けてからの裏拳気味の振り上げに。
- **s3 暗連 → 改良**: 突き一発ではなく、姿勢を変えながらの三発（低→中→高）。
- **奥義 暗連・黒天烈掌 → 刷新**: **ムービー案（7カット。最も速い）**: 一発ごとにカメラが反対側へ切り替わる連打（4カット、各 0.25 秒前後。相手は毎回逆へ弾かれる）→ 相手の背後へ回る残像 → 真下から、落ちてくる拳 → モグゾーの決めと逆に、背を向けたまま振り返らない。
