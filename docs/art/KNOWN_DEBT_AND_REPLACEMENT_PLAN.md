# 既知の妥協点・今後の差し替え計画

優先度A（実機で目立てば早めに交換）
1. ヨミカゲ: 包帯/手甲の側・形の不安定フレーム
2. ヨミカゲ: 頭身が縦長/頭小さめに見える動的フレーム
3. 奥義カットイン: 4 digitsを外れて見える大きな手（モグゾー、ヨミカゲ、ダークモグゾーを優先確認）
4. 通常HIGH等に焼き込まれたヒット火花（通常技VFXなし方針のため）

優先度B（遊べる状態を優先し後回し）
- タキマルの複雑な投げ時の手指
- バレットの木の実が小さく/不明瞭になるセル
- ハクマの一部3/4寄り顔
- 各キャラ固有技に焼き込まれた土煙・軌跡（後送VFXとの二重化防止）

差し替え構造要件
- 1フレーム単位でファイル差し替え可能にする
- animation manifestでpose/frame IDを固定し、画像hashだけ交換可能にする
- technicalDebtフラグをmanifestに持たせる
- 差し替えでBAL/当たり判定/入力定義を変更しない
