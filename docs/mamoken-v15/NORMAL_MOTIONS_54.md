# マモ拳 v15｜9体×6通常技＝54本の3Dモーション差分

## ユーザーの要望と制作主体
「Claudeにさせる分も含めて実装させて」。本チャットからClaude Code本人の実行セッションは呼び出せないため、**ミオが既存のClaude/Blender制作済みの9体リグをベースに追加アニメーションを実装**。Claudeに作らせたと偽称しない。Claude担当領域の現物を残すため、単なる色替え/カメラ角度だけでなく、**全54技の回転キーフレームを個別に加工し、ロード可能なGLBにビルド**する。

## 素材と技の編集方式
- 編集正本＝`normal-motifs-v15.js`。全9体×6技のコンセプト、コンタクト時点、振りの強さと人体部位の角度を明示。全54技は別gestureの実ボーン操作。姿勢が技間で分かれ、キャラ固有の腕/脚/尾/重心を強調する。
- `normal-clip-builder-v15.mjs`が既存の`exp/fable-3d/chars/<id>/<id>.glb`の6通常技`stand_light/stand_heavy/crouch_light/crouch_heavy/air_light/air_heavy`のアニメーション**キーをサンプリング**し、本人用の新しいコンタクト姿勢を骨のクォータニオンに加える。
- `pack-normals-v15.mjs`で9つの**animation-only glTF2.0 GLB**を決定的に再生成。元GLBのMesh/Material/Texture/毛並み・骨格と既存9奥義10秒動画は改変しない。
- build:pagesが`/normal/v15/<id>_normals.glb`を配信。`main.js`は元GLBと並列にロードし、`models.js`が本物の`v15_stand_weak`などを優先。失敗時は技未完成を隠さず起動エラーで返す。
- `clipChange`は元モーションの実フレーム数を参照して、v15 Battleの発生/持続/硬直へ同期。既存v14の27必殺・9奥義・被弾・カウンターはそのまま。
- **実機レビューが必要**：関節のめり込み、足の地面接触、拳の向き、リグ名の差、カメラから見える攻撃シルエット、スマホメモリ/発熱。CIではキー/GLB読込/全54技/全81映画で客観検証。

## 次のクリエイティブ品質
現段階で新規キーフレーム付きGLBが動くことは保証対象だが、Claude自身による造形・演技の独立レビューやBlenderソースでの手付けアニメ制作が完了したわけではない。実装の成果映像をレビューして、構えや脚の強調に不自然さがあれば元リグを保ち差分に戻して調整する。
