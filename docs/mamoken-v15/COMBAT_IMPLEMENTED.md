# v15 Combat prototype — actual code

**本人の希望**：9体固有の空中/地上機動と動作の発生・隙、弱→弱・弱→強・通常→必殺キャンセルを追加。ここでは本当にBattleロジック・データを変更し、旧v14のシネマティックとP0横持ち/プラクティスは保持。

## 追加した実装
- `fighter-style.js` に9体別の airSpeed / airAccel / airFriction、dashFrames/ダッシュ後隙、弱チェーン上限、弱/強の発生・硬直微調整データを分離。新数値はまだユーザー採否前の試作仮値。
- `balance.js` の6通常技は既存ダメージ/ reach を保持しながら各キャラの開始/硬直差を付与。
- `battle.js` で各キャラの空中横操作を加速度＋慣性ベースに変更。ダッシュ距離は維持し時間と後隙を分離。
- 接触済み通常技（hit/guard）のみ `weak→weak`／`weak→heavy`／`normal→s1/s2/s3` をキャンセル可能に。空振り、押しっぱなし、弱連打の上限超過は不可。ヒットストップ中に押されたボタンを9F以内に消費。技の本来のリカバリを超えたキャンセルはしない。
- 同じ連携中の被弾には下限60%まで段階的なダメージ補正。カウンター/アーマー/クラッシュの無効化判定は元のコードを優先。既存のピスケのチェイス/チルカのフェイント/ダークモグゾーの暗連を分離。
- 追加`cancel`/`combo`のイベントで視覚化やプラクティス統計に使えるようにした。

## 実装されていないもの
- Claude作成の新しい通常技モーション/各技専用クリップはこのPRでは未追加。キャンセル時に既存の弱/強モーションがリスタートする。
- 厳密な格闘ゲーム式のガード硬直/フレーム有利不利の全技調整と、トレモのヒットボックス可視化/録画機能は別の品質工程。
- AIの候補数値は本番採用前に対戦感・9×9 CPUの検査を実施する。mainやv14は未マージ。
