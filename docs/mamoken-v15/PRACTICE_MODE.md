# マモ拳v15 プラクティスモード

本人指示：「v15進めよう、同時にプラクティスモード追加しといて」。

- キャラ選択に通常対戦/プラクティスを追加。プラクティス時は相手の停止/ガード/CPU、位置リセット、攻撃コンボHITS/DMG/直近ダメージを表示。
- 練習中は体力/ドライブ/奥義ゲージを自動回復、時間∞。被弾/ガード硬直・モデルのリアクションはBattleの本物を使い、ゲーム性能の正本は変更しない。ガードダミーは上中段/下段対応。
- 位置リセットはGLBを再ロードせず新Battle状態へ切替。尻尾の正しい当たり判定元データは保持。
- 右6ボタン・iPhoneの横持ち固定・奥義の9体10秒ムービーとスキップは従来どおり。
- キャラごとのキャンセル設計は別のv15制作レーンで実装。自動テストとChrome実機相当の検証まで実施し、本人へ逐次試遊を繰り返し求めない。
