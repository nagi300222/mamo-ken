# v15.1 通常技の役割（調整案）

PR195の移動・奥義・固有能力を保持し、以下は通常技の明示性能で表現する。数値はAIの試験案であり本人確定値ではない。アート接触監査後にリーチを最終照合する。

|キャラ|通常技の強み|残す弱点|
|---|---|---|
|モグゾー|5F立弱から2回の弱チェーン、安定した弱強必殺。弱→必殺1はガード時も可能|最速組には競り負け、強攻撃のガード後は反撃を受ける|
|ピスケ|4F立弱、3弱まで。脚の強攻撃と空中速度で接近|小さい単発ダメージ、低体力、強技をガードされると不利|
|ゴダン|弱47・強96の重撃。強ヒット後は先に動け、弱強対空必殺が連続ヒット|立弱7F、弱→弱は不可。強の大きな空振り/ガード硬直と遅い移動|
|ハクマ|4F持続の掌、押し返しと鉄壁、強ヒット後+3F|発生7F、弱は2回。攻撃を外すと接近し直す必要がある|
|チルカ|4F立弱と短い確認連係、爪の軌道とフェイント必殺|小さい単発ダメージ、2弱上限、ガードから無条件で必殺へ逃げられない|

## 実際にテストしているルート

全9体：密着付近0.35mから立弱→立強→必殺2。初段だけ無防備、その後は相手がガードを保持する条件でも3実ヒットする。キャンセル入力はヒットストップ解除直後。左右向きの両方を検証。初段が射程外、または確認窓を8F以上超えると失敗する。新しい実測リーチを取り込んだ後、必要距離を再測定する。

弱チェーンの上限と強→通常禁止に加え、壁際600Fの最速弱入力でもガード復帰できる隙間ができることを検査。ガード硬直を被弾硬直と誤認して強制ヒットに変える旧処理は修正した。

CPU反復は挙動と偏りを発見するためのもの。高速組優勢が残るため、アート統合前の勝率を最終的な対人バランスの合格としない。
