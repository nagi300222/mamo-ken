# ARCADE / SURVIVAL 実装・検証

本人依頼 #202。基準は v15.1 #199（78dd0c6）、演出はClaude #207、ゲーム統合は #205。mainと元Draftはマージしていない。

## 実装

- `RunController`が対戦順、2ラウンド先取、CONTINUEと終了を管理する。各ラウンドは元の`Battle`を新規生成し、判定・ダメージ・技性能を別実装しない。
- ARCADEは7人のシャッフル＋第8戦FINAL、試合ごとの背景・旧本体の1往復台詞、敗北/引分から同じ相手と景観へフルHP再戦。CONTINUEは無制限。ラウンド勝利には勝利映画を出さず、試合勝利のみ上映する。
- SURVIVALは1ラウンド、HPのみ持越。勝利数1–15は最大HPの1/2、16–30は1/3、31以降1/4回復し上限HPへ切る。状態異常・能力蓄積・ゲージ・クールダウンは新Battleで初期化する。
- CPUは戦数1–15=Lv1、16–30=3、31–45=5、46–60=7、61以降=9。通常15戦/ダーク8戦ブロック末尾がダーク戦。ダーク使用時のみミラー戦。SURVIVALはVSと勝利を短縮し、敗北/引分は終了する。
- 連勝・残HP・回復・次Lv・ボス・自己ベストを表示する。ベストは端末のローカル保存をAI初期案として採用した。サーバーなしで自己記録を残せ、保存が拒否されても連戦を続けられるため。
- 6景観は村の家/柵、雪峰と草原、岩の峡谷、川と橋、地下アーチと松明、新月と石柱を別々の3Dメッシュで構築。元のグリッド道場は通常対戦・Practiceに残す。
- 奥義の間は元の凍結機構を利用。KO演出の後にラウンド/試合結果を1回だけ処理し、通常の終了とスキップで同じ経路を通る。

## 旧版との境界

正本はIssue #202に明記された旧Wikiの規則。旧実2D `dist/mamoken_mobile.html`では、通常ARCADEの前半からFINAL相手を除外し、通常SURVIVALの第7戦にミラーを入れている。これはWiki/Issue #202の「自分以外から7人」「ダーク使用時のみミラー」と異なる。本実装では今回の明示仕様を優先し、その差を黙って忠実再現済みとは呼ばない。台詞は同HTMLの`ARCADE_DIALOGUE`からそのまま移植した。

CPUは旧9Lv表の思考間隔・反応遅延・防御率・攻撃頻度・ダウン追撃率をデータ化して3Dの行動へ適用している。旧2D固有のMIKIRI/回避/適応AIそのものを移植したのではなく、既存3Dのガード・後ステップ・咆哮で近似する。モード選択にも「旧版近似」と表示する。通常対戦/Practiceの従来3難度は変更しない。
