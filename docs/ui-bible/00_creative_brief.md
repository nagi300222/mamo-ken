# 00｜マモ拳の画面は何を約束するか

## 0-1. 最初の約束
1. **主役はマーモットの表情・動き・対戦の駆け引き。** パネルは主役の後ろへ退く。ただし必要なHP・資源・入力の場所は隠さない。
2. **同じゲームの5つの遊びに、違う表情がある。** 対戦、プラクティス、アーケード、サバイバル、キャラクリ＋探索は、それぞれ別の感情の流れを持つ。
3. **情報を説明ではなく行動に結びつける。** 文字が増えなくても「何を押して何が起きるか」が分かる。初回は学び、再訪は速い。
4. **選ぶ行為自体を楽しめる。** キャラが顔を向ける、選択が伝わる、戻れる、待たされすぎない。無意味な演出や行動不能時間は増やさない。
5. **勝負の公正さを傷つけない。** 試合中のタイマー・HP・資源・攻撃判定・ゲーム入力の既存実装をUIの都合で変えない。
6. **独自性は装飾品ではなく体験の全体。** 同じ色・木札・印章を全画面へ貼るだけで「統一」と呼ばない。

## 0-2. 想定プレイヤー
| ペルソナ（仮説） | 目的 | 失敗しやすい場所 | 要求 |
|---|---|---|---|
| 初めて格ゲーを遊ぶ人 | マーモットを選んで技を出す | 技名、入力、間合い、失敗理由 | 導線・フィードバックの即時性、困った時に戻れる |
| 格ゲー経験者 | 対戦の有利不利と駆け引き | 不要字幕、入力遅延、ゲージの視線移動 | 中立な表示、同条件での再戦、高速操作 |
| スマホ中心の人 | 両親指で手軽に遊ぶ | 指がキャラを隠す・誤タップ | タッチ領域と舞台の両立、持ち替え不要 |
| キャラクター創作者 | 外見を試し、相棒に愛着を持つ | 自作プレビューが狭い・保存が不安 | 大きな3D、試着、戻す、確実な保存 |
| 探索を楽しむ人 | 村を歩きNPCと交流 | 方向感覚・操作説明が画面を覆う | 行動で誘導、近づく時だけアクション |

これは利用実績ではなく設計仮説。実際の人間テストの結果で修正する。

## 0-3. ゲームデザイン思想を現場の問いに変える
『桜井政博のゲーム作るには』の公開UI編・設計に関する考え方を**ミオが実務へ翻訳した問い**。桜井氏本人によるマモ拳の評価や直接の設計提案ではない。
- わかりやすさとスタイル性 → 画面の魅力を削って分かりやすくしていないか。逆もないか。
- メニューが世界を語る → 知らない人がメニューを見て、マモ拳で何を楽しむゲームか想像できるか。
- 重要なものを大きく → 視線最初の0.5秒で最優先の行動と対象を掴めるか。
- 言葉がなくても伝わる → ラベルが消えても選択中・決定可能・危険・完成が伝わるか。
- スキップ/ポーズ・ボタン設定 → キャラの見せ場を尊重しながら操作権を奪っていないか。
- HUD → 対戦のために見る情報が、主役の接触と競合しないか。

## 0-4. 3つの品質ゲートは別
**機能**：正しい入力・対戦・セーブ・キャラクリ・奥義・連戦・復帰。
**意匠**：独自の構図、画面ごとに異なる見せ場、文字、グラフィック、調和。
**体験**：初見の選択、操作の楽しさ、迷い、音、テンポ、親指、スキップ。
6軸100点のQAはこのうち一部を測るもので、商業ゲームの美術的完成度を保証しない。

## 0-5. 現行のアンチパターン
- A1「画面を問わず同じ大きな共通ヘッダー」→ 試合・勝利・村の時間の文脈に不要。
- A2「カードの枠と説明を積むだけ」→ Webアプリのダッシュボードに見える。
- A3「名前・役割・人数・選択説明を繰り返す」→ キャラより文章が主役。
- A4「全画面に細線・小文字を足す」→ 意味のない精密感、試合中に読めない。
- A5「何でも常時設定」→ 主操作と副操作の区別がなくなる。
- A6「過度なシンプル化で個性も失う」→ 初期の平板なAI製UIへ戻る。
- A7「完成イメージと実ゲームの同期がない」→ 静止画だけ格好よく、実装で崩れる。

## 0-6. 設計レビューの5つの質問
1. この場面で人は何をするか。何を感じたいか。
2. 何を見れば次の操作を選べるか。説明が不要な理由はあるか。
3. 同じ情報がほかの場面でも見えるなら、今ここで要るか。
4. その表示がキャラ・ステージ・攻撃の見せ場を奪っていないか。
5. 次の場面に移るとき、音・動き・操作・フォーカスが連続しているか。

この5つに明確な回答がない要素は、単に装飾が綺麗だからという理由だけで採用しない。
