# 01｜作品のアートディレクション 3候補

本章は色違い3案ではない。**同じマモ拳のゲーム体験を、異なる構図・動き・文字・音の規則で表現する候補**である。Figmaの各6画面は**編集可能なレイアウト検討**であり、マモ拳の実モデルを再現した完成美術ではない。

## AD-A：拳祭・舞台型
Figma: https://www.figma.com/design/afaB1eVmV6uOnDZR40t0Kr?node-id=3-54

**核**：「山で開かれるマーモットの格闘祭」。ライバルと出会い、決定した瞬間からショーが始まる。
- 構図：大胆な余白対比、斜め/縦方向のアクセント、巨大な選択中キャラ。
- 文字：大見出しは肉厚、短い名詞。補足の文字と一対一のコントラスト。
- 色：深い森林色、暖色の炎・琥珀、生成り。競技中の赤/青など資源色の意味は別ルール。
- モード：対戦を舞台の中心に、他の4モードは進行方向に配置。選択に合わせて舞台の光とカメラが変化。
- キャラ選択：9体の顔/体の差が分かる一覧と、選択時の大きな登場/名前。
- 戦闘：全画面の舞台とヒットの迫力。常時の巨大なロゴ・ボタンを置かない。
- 勝利：主役のポーズに合わせ大文字が出て退く、再戦をすぐ押せる。
- 音：乾いた太鼓・木の打音、決定には短く歯切れよい音、勝利は長い余韻。
- リスク：演出がくどい／常時派手で疲れる。ゲーム中はHUDを引き算、スキップと動き軽減必須。

## AD-B：山嶺・競技型
Figma: https://www.figma.com/design/afaB1eVmV6uOnDZR40t0Kr?node-id=3-222

**核**：「マーモットによる本格対戦競技」。見てすぐ比較でき、読み合いに集中できる。
- 構図：ステージを広く、一列の大きな選択と水平の情報帯。視線が左右のHP・中央の試合へ戻る。
- 文字：太い数字・統一した字幅、ラベルより状態が主。対戦中の超小文字は禁止。
- 色：青黒・岩色、シアン／琥珀、ニュートラルな背景。ゲーム資源の意味色は一定。
- モード：一つの大きな舞台、横並びのモードスイッチ。キャラは画面の光源で存在感を出す。
- キャラ選択：9名のサムネイルを下部一列に、選択キャラの立ち姿を中央に大きく。
- 戦闘：コンパクトな上部HUD、広い中心、端の6操作。UIは動かず試合の邪魔をしない。
- 勝利：スコア・勝者・再戦をスピーディに表示。
- 音：短い電子×物理打音、レバー操作の確実な応答、対戦はヒット音優先。
- リスク：機能的すぎて無個性な競技ツールになる。キャラ独自の反応・光の動きで補う。

## AD-C：旅人・絵巻型
Figma: https://www.figma.com/design/afaB1eVmV6uOnDZR40t0Kr?node-id=3-391

**核**：「山のマーモットたちの暮らしと稽古の記録」。友達や自作の相棒への愛着と冒険。
- 構図：村の道、地図、工房、記録紙など世界に存在しそうなインターフェース。紙そのものがボタンを隠すことは禁止。
- 文字：語りは自然体。地図や成績は短い記号・場所・勝敗を中心。
- 色：深い樹木、土、布、手触りのある紙。可読性が最優先でテクスチャは文字の下では抑える。
- モード：山の遊び場を選ぶ案。5つのモードを地図上のスポットに対応させる。
- キャラ選択：図鑑風の描写と選択した仲間との対面。顔を重視。
- 戦闘：**演出的であっても紙パネルでステージを狭めない**。HUDは世界観のエッセンスのみ。
- 勝利：仲間の記録が残る達成感。結果後は再戦・散策に戻れる。
- 音：木・鈴・紙・足音など環境に近い音。格闘中の音のキレは譲らない。
- リスク：ほのぼのしすぎて格ゲーの強度が下がる。試合は対戦の熱へ切り替える。

## 比較：どの課題を解くのか
| 評価 | A 拳祭 | B 山嶺 | C 絵巻 |
|---|---|---|---|
| キャラの登場の高揚感 | 強い | 中 | 親しみ |
| 競技としての瞬時判読 | 中〜強（設計次第） | 最も強い | 配慮が必要 |
| 3D探索との一体感 | 中 | 中 | 最も自然 |
| キャラクリの楽しさ | 強い | 作業性が高い | 愛着が強い |
| 小さい横画面での破綻リスク | 文字と演出 | 細すぎる表示 | テクスチャ・柔らかな装飾 |
| AI製Web画面っぽさを避ける鍵 | 映画的な視線とテンポ | 無駄な形式を捨てる | 世界内UIと自然な操作 |
| 私の初期仮説 | メニュー/VS/勝利に強い | Battle/Practiceに強い | Creator/Storyに強い |

**重要**：各画面でバラバラにA/B/Cを採用すると別ゲームに見える。優先順位は「作品の表現の主語を1つ選ぶ → 画面ごとの使い勝手を借りる」。採用後は全画面の文字・光・SE・動作に共通文法を通す。

## 最初の選択（未決定）
- AD-00：全体A／B／C／混成の核を決める。
- CHAR-PRES：キャラをステージに登場させる／ポートレート中心／記録画面のように親しみを出す。
- NAV-HOME：舞台とモード旗／横一列の選択切替／村の地図。
- AUDIO-TONE：祭囃子と打撃／精密でドライ／自然物と軽やかさ。

採用はデザイン案と実ゲーム上の3秒〜20秒の映像で判断し、色の好みだけで全体採用しない。
