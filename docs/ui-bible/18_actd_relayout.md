## 本人が今回指定した変更
- 奥義とギュイーンが必殺の右端より先へ出ないようにする。
- 攻撃ボタン群全体を右寄せする。必殺の右側にステージの空きができる。
- ギュイーンは右側を縮めた分と同量を左側でも縮めて、長さの中心を保つ。
- 弱をギュイーンへ近づける。
- 掴みは奥義と**同じ大きさ**にし、どちらも丸ではなく湾曲した豆型輪郭とする。
- 掴みを短くした空間で強を掴みと弱の間へ寄せる。
- **必殺・強・弱の可視サイズは変えない。ボタン間の隙間の感覚も保つ。**
- 左スティック/前後ステップ/背景ステージ/中央キャラなどのその他機能は今回の変更対象外。

## 変更を受け入れるときのチェック
1. 元画像に重ね、**円3個（必殺・強・弱）の直径を元のまま**にしているか。
2. 掴みと奥義が同一輪郭の鏡像になっており、**同じ大きさ**か。
3. 奥義とギュイーンのいちばん右が必殺のいちばん右より先に出ないか。
4. ギュイーンの長さが左右から同程度削られ、弱との空白が以前より狭いか。
5. 強と掴み、強と弱、弱と必殺、必殺とギュイーンの間隔が不自然に開いたり重なったりしないか。
6. その他のステージ・ジョイスティック・キャラクターを勝手に移動していないか。

ゲームの実機試験とアートの色・材質の再決定は別工程。**本人が「これでOK」と言うまでは確定配置として扱わない。**
