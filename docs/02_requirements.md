# マモ拳（仮） 要件定義 v1.0

優先度: **MUST**(v1必須) / **SHOULD**(v1で入れたい) / **COULD**(余裕があれば) / **FUTURE**(v2+)
数値はすべて `03_データ設計` の balance 定数が正。本書は挙動仕様を定義する。

## F-xx 機能要件

### F-01 入力システム（MUST）
- パッド（画面下50%）を **3段×2列の6ゾーン** に分割。左列=ガード（上/中/下）、右列=攻撃A（上/中/下）。段境界はパッド高の1/3ごと、列境界は中央。
- 右列タップ = A（**touchstart時点で即発生**。レスポンス優先）。
- 左列 = ガード。**押下中ホールドで継続、離すと解除**。段の変更は一度離してから。
- **相手方向（右）フリック = S咆哮**。開始ゾーン不問。判定: 累積dx ≥ 60px（論理座標）かつ 300ms以内。
  - 右列開始のフリックは「A発生 → 発生中にフリック成立 → **Aの発生をキャンセルしてSへ移行**」で解決（タップ遅延ゼロとフリック共存の裁定。ゲージ不足時は何も起きない）。
  - 左列開始のフリックはガード解除してS発動。
- 入力バッファ 8F（硬直中の先行入力保持）。
- マルチタッチ: 各タッチを独立処理（状態機械側が自然に排他。ガード中のA入力は無効）。
- PC開発用にマウス対応（クリック=タップ、ドラッグ=フリック）。

### F-02 通常攻撃A（MUST）
- 上/中/下の三段。フレームデータ（発生/持続/硬直）・ダメージは balance 準拠。
- **同段ガードで防がれる。段違いガードは被弾。**
- ヒット時のみ次のAへチェーン可（ヒット後 CHAIN_WINDOW 以内、**同段連続不可**、最大3連、コンボ補正あり）。移動がないため攻撃は必ず接触する（空振りは概念上のみ）。

### F-03 ガード（MUST）
- 段一致でガード成立 → blockstun、ガード耐久減少（F-07）、双方Sゲージ増加。
- **ジャストガード**: 攻撃ヒット確定時点で「ガード成立からの経過 ≤ JUST_WINDOW」なら競り合いへ（F-05）。削りなし。
- blockstunから復帰してホールド継続中のガードは **guardAgeを引き継ぐ**（連続ジャスト防止。ジャストには押し直しが必要）。

### F-04 相打ち競り合い（MUST）
- 双方のAが**同一フレームで接触し同段** → 競り合いへ。段違い同時は双方被弾（相打ちダメージ）。

### F-05 競り合い「ギュイーン」（MUST）
- 発生条件: F-03ジャスト or F-04同段相打ち。
- 演出: ゲーム時間停止、ズーム/集中線、ギュイーンSE、両者押し合いポーズ。
- パッドが**三択UI（上 / 右下 / 左下）**に変形。制限 1.5秒。未入力はPRNGでランダム決定。
- 三すくみ: **上は右下に勝つ / 右下は左下に勝つ / 左下は上に勝つ**。
- 敗者: クラッシュダメージ + ノックバック。勝者: **奥義ストック+1**。あいこ: ダメージなしで仕切り直し（再抽選しない）。

### F-06 Sゲージ / S咆哮（MUST）
- 蓄積（攻撃側優遇）: A命中+12 / A被ガード時の攻撃側+8 / ガード成功+5 / ジャストガード+10 / 被弾側+4（キャラ係数 sGainMul を乗算）。最大100。ラウンド跨ぎで**持ち越し**。
- 発動: ゲージ100で相手方向フリック。全消費。
- 性質:
  - 全段攻撃。**どの段のガードでも防御可能**だがガード耐久を大きく削り（-45）+ 削りHPあり。
  - 発生前半に**スーパーアーマー**（のけぞり無効・被ダメ50%）。
  - **被hitstun/blockstun中でも入力可**＝コンボ・固めへの割り込み（バースト）。発動時、被コンボカウントはリセット。

### F-07 ガード耐久（MUST）
- ガードゲージ100（キャラ差あり）。A被ガード-8、S被ガード-45。非ガード時のみ 0.25/F 回復。ラウンド開始時全回復。
- 0で**ガードブレイク → 気絶90F**（全行動不可、確定反撃）。復帰時ゲージ50。

### F-08 奥義（MUST）
- 競り合い勝利で+1、最大3。ラウンド跨ぎ持ち越し。3到達で発動可能。
- **モードA（デフォルト・仕様準拠）**: 到達した瞬間パッド全域が奥義ボタンに変形、通常操作不可。タップ（被hitstun中でも可）で発動。
- **モードB（設定切替用に実装のみ）**: パッド中央にボタン出現、通常操作可、長押し0.3sで発動。
- 演出: 暗転 → カットイン（キャラ顔＋技名） → フラッシュ → **必中・ガード貫通・競り合い不可**の大ダメージ。使用後ストック0。演出中はゲーム時間停止・相手入力無効。
- 双方同時発動可能状態: 先に入力した側が発動（同一フレームはPRNG）。

### F-09 ラウンド / 試合管理（MUST）
- HP1000、60秒、2本先取。KO / タイムアップ（残HP多い方。同値は双方に星なしで再戦）。
- ROUND n → FIGHT! コール、K.O.スロー演出、リザルト、リマッチ。

### F-10 CPU AI（MUST）
- 思考間隔12F、反応遅延6〜18F（PRNG）。反応型（相手攻撃検知→対応段ガード試行、成功率パラメータ）+ 重み付き自発行動。
- S: 被コンボ中の割り込み確率 / 相手行動への差し込み確率。奥義は到達後即発動（モードA準拠）。競り合いは等確率ランダム。
- 難易度パラメータ（reaction, guardSkill, aggro, clashBias）を外出し。v1は1難易度。

### F-11 演出（MUST）
- ヒットストップ（A: 5F / S: 9F）、画面シェイク、ヒット/ガードスパーク、ダメージ数字、コンボカウンタ、競り合いズーム＋集中線、KOスロー、暗転カットイン、勝敗ポーズ。

### F-12 サウンド（MUST・仮素材可）
- SE: ヒット / ガード / ギュイーン（競り合い）/ 咆哮 / ガードブレイク / KO / 奥義 / UI。プロトタイプはWebAudio合成音で代替可。
- BGM: バトル1曲（Suno差し替え前提、ループ点メタ付きフックのみ先行実装）。

## N-xx 非機能要件

| ID | 内容 | 優先度 |
|---|---|---|
| N-01 | ロジック60F固定tick（accumulator方式）・描画は可変 | MUST |
| N-02 | **決定論**: core層は (state, inputs, seed) の純関数。乱数はseed付きPRNG（mulberry32）のみ。core内 Math.random / Date 禁止。将来のオンライン/リプレイの布石 | MUST |
| N-03 | **外部通信ゼロ**。fetch / WebSocket / analytics 禁止（v1） | MUST |
| N-04 | TypeScript strict。core層DOM非依存。Vitestユニットテスト（三すくみ全表 / ジャスト窓境界 / ゲージ計算 / ブレイク遷移 / コンボ補正 / 決定論リプレイ一致） | MUST |
| N-05 | 縦画面固定・セーフエリア対応・375×667〜430×932で崩れない。PCマウス動作（開発用） | MUST |
| N-06 | アセットはスプライトシート+JSON規約で差し替え容易。v1はプログラム描画プレースホルダ可 | MUST |
| N-07 | AudioContextはユーザー初回タップ後にresume | MUST |
| N-08 | ミッドレンジ端末で60fps維持、オブジェクトプールでGCスパイク回避 | SHOULD |

## 暫定決定リスト（Hub裁定済み・変更はbalance/設定で吸収）
1. ガードはホールド式 2. プレイヤー左固定 3. あいこは仕切り直し 4. 競り合い未入力はランダム 5. v1キャラ3体（モーション共通・性能差分） 6. 奥義デフォルトはモードA（強制変形） 7. Sゲージ・奥義ストックはラウンド持ち越し、HP/ガードはリセット 8. 右列フリックは「A発生キャンセル→S」で裁定
