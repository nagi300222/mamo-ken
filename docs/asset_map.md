## 2. 使用画面マップ（v0.5）
| 素材 | 画面 | 使い方 |
|---|---|---|
| standing×3 | タイトル / キャラ選択 / リザルト | タイトル=3体ローテ表示。選択=カード内に大きく。リザルト=勝者を表示。**白背景なので事前に背景除去して透過PNG化してから配置**（remove.bg等・無料）。未処理の場合はCode側でしきい値白抜きを実装してもよい |
| clash_guiin.png | ギュイーン突入演出 | 突入26Fの間、全画面にズームイン表示→三択UIへ。対戦カードと絵の組み合わせが不一致でも「演出カット」として許容（将来キャラ別差し替え） |
| roar_moguzo.png | 咆哮発動演出 | モグゾーの咆哮接触時に0.4秒フラッシュ表示。**ピスケ/ゴダンは未生成のため現行プログラム演出にフォールバック** |
| cutin_moguzo.png | 奥義カットイン | モグゾーの奥義演出を画像表示に差し替え（テキストは焼き込み済みなのでゲーム側テロップは重ねない）。他2キャラはフォールバック |
| （画像不要） | パッドのリングロゴ | 「マモ拳」ロゴはCanvasテキスト描画で薄く敷けば十分。画像化不要 |

実装原則: **画像が無いキャラ/場面は必ずプログラム描画にフォールバック**する（素材が段階的に増える前提の作り）。戦闘中のキャラモーションは**v0.5ではプログラム描画**、v0.6でキーポーズスプライトへ移行（別紙「戦闘グラフィック移行計画」参照）。
