## 実装した内容

- 81技の現行性能・役割/弱み・原GLB SHA256・クリップ・既存接触データと候補停止Fを `baseline/MOVE_CATALOG.json` と `.md` へ凍結。
- `fight-feel.js`: 弱4〜6F、強7〜10F、ガード3〜5Fの対称停止。打撃面/重さに対応した音・粒子・微振動の共通イベント。空振りに接触音/ヒットストップは出さず、技開始の風切りだけを鳴らす。通常打撃FXは既存の実測表面の高さ/前方位置を使う。必殺の新しい打点はClaude測定後に接続する。
- `combat-audio.js`: オリジナル合成の弱・拳・蹴り・岩・掌・爪・肘・尾・弾・ガード・風切りを分離し、独立音量/ミュートを保持。音量だけで重さを表現しない。
- 長い停止で最初の先行入力が消えないよう、入力バッファを技の実フレームで評価。有限のキャンセル窓、ガード時の制限、連打上限は保持。
- `special-balance-p3.js`: 19近接必殺だけ `hitstun` を明示。発生/持続/硬直/威力/reach/knockback/cancelは変更しない。6飛び道具、投げ、当て身、奥義の既存時計は保持する。
- `normal-contact-source.js`: 未承認のアートは有効化しない。`normal-contact-overrides-p3.js` の承認済みデータは現時点で `null`。v17の著者メタデータと別の実スキン計測54行を `createP3ContactDelivery` で照合し、初めて表面/時計を同時切替する。自作外見の `move.customContact` がある場合はその時計を優先する。

## 必殺hitstunを調整する理由

基準では投げ/当て身を除く25必殺が、最速命中後でも-6〜-24Fだった。例えばゴダン肩当て-21F、ハクマ連続突っ張り-18F、バレット尾薙ぎ-14F。ダメージ由来の短い被弾硬直と長い技の戻りが噛み合わず、確定コンボの最後を当てても先に殴り返される。

候補では近接19技の最速Hit差を役割別に概ね-1〜+2Fへ改善し、Guard/Whiffの長い反撃リスクを保つ。飛び道具は離れた位置の牽制が役割なので、近距離で負になる元の被弾硬直を保持。遅いactive接触の有利差、押し出し距離とガード復帰、永久コンボは追加計測対象。

## root統合フック

道場/Storyの各イベントで `presentCombatFeedback(event,{audio,impact,shake,effectsEnabled})` を呼ぶ。`true` の場合は既存の汎用接触音/粒子だけを省き、HUD・KO・当て身アニメの意味処理は継続する。`impact` は `{effect,point,characterId,scale,lifeFrames}` を受け取り、既存の共有ジオメトリへ渡す。音を二重再生しないこと。

共有version APIは `ACTIVE_NORMAL_MOTION_VERSION`（現在`v15`）、`NORMAL_CONTACTS`、`NORMAL_HURT_BOUNDS`、`NORMAL_CONTACTS_VERSION`。Claudeのv17素材が承認された場合、道場の読み込みだけでなくAvatarFactoryも同じパックを選び、Storyと道場の時計を一致させる。原GLB/骨格を再生成せずP3モーションだけを変える。
