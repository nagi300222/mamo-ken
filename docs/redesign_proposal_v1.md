## 1. エグゼクティブサマリ
- 操作は **「見合いと交差」方式** に刷新: ボタン枠を廃止し、右半分=タップの高さで攻撃・左半分=ホールドでガード。左のジャストタップ＝新アクション **「見切り」** でギュイーンを能動的に起こせるようにする
- フレームは **Punch-Out!!文法** に転換: 全攻撃に「読める予備動作（テレグラフ）」を付け、発生を14/22/30Fに再配置。「見てから対応できる技/できない技」の境界を意図的に設計する
- 新要素は **集中（自動スローモーション）** を採用。満タン時、相手の攻撃発生に反応して0.25倍速+ズームが入り、見切り/ガード/合わせの猶予が生まれる。疑似ハイスピードバトル演出を兼ねる
- 下段は **ダウン技** に昇格（SF6の大攻撃/スイープポジション）。1発150の大リターン・被ガード-18の大確反

### 推奨: A+C+E のハイブリッド
**右半分＝攻めゾーン**
- タップ（触れて離す）の**高さ＝段**。上1/3=上段 / 中1/3=中段 / 下1/3=下段。発火はリリース時（Eを吸収）
- ヒット後、高さを変えてタップ＝チェーン（中→上→下ルートは維持）
- 右フリック＝咆哮（現行踏襲）

**左半分＝守りゾーン**
- ホールド＝ガード（統一ガード維持）
- **ジャストタップ（100ms以内に離す）＝「見切り」**: 相手の攻撃が触れる±5Fに重なればギュイーン発生。外すと見切り硬直22F（ガード不能）。ストIIIブロッキング/サムスピ見切りのタッチ翻訳。ガード擦り対策も兼ねる（現行のREGAPは廃止し、こちらに一本化）
- 下フリック＝つかみ（「潜り込む」ジェスチャー）

**画面**: ボタン枠を全廃し、中央の縦ラインと左右の薄いゾーンヒントのみ。視線は上半分の相手に固定される（格ゲーの視線構造）。

**1ラウンドの指の動き（時系列）**
0:00 右手親指が画面に軽く触れて待機。相手が低く構えた（下段テレグラフ+低音SE）

0:05 起き上がりの見合い。相手の中段テレグラフ（速い）に反応できず被弾

## 4. T3 駆け引きの層
- ジャンケン検証: 「打撃>つかみ>ガード>打撃」に「見切り>打撃、空振り見切り<全部」が乗り、5すくみ化。見切りの空振りリスク(22Fガード不能)が抑止力なので壊れない
- 意思決定頻度: テレグラフ導入で1交戦=見る→選ぶ→結果の3〜5秒。60秒で12〜15交戦、うちギュイーン2〜4回、奥義0〜1回が目標密度
- 逆転装置: ピンチ時は見切り窓±5F→±7Fに拡張（現行ジャスト補正の移植）。ギュイーン連勝ボーナス・奥義は現行維持

## 5. T4 新規要素（2個採用）
1. **集中（自動スロー）** — 採用。ゲージ100: 被ダメ×0.15 / ガード成功+8 / 見切り成功+30で蓄積。満タン中に相手の攻撃が発生した瞬間、0.25倍速×実時間0.6秒+ズーム1.3倍が自動発動（全消費）。相手視点では「光っている間は打撃を振ると返される」＝つかみ/様子見に切り替える択の圧になる。演出テキスト「——マーモットの0.5秒は、人間の0.05秒」
2. **読まれ表示** — 採用（低コスト）。同系統の行動3連続で頭上に「読まれ!」アイコン。次の同行動は相手AIのカウンター率が跳ね上がる（既存のmash検知の可視化）
- 土俵際（押し出し）は面白いがラウンド設計が変わるためv2送り。観客ヒートはルールに絡めず、ギュイーン/奥義時に観客が沸く演出のみ実装

## 6. 新仕様での1試合の流れ
INTRO: 両者テレグラフの構えを見せ合う演出 → FIGHT!
序盤: 中段の差し合い（読み合い）とガード確反でリズムを作る → 中盤: ガードが増えたところにつかみ/下段、見切りの置き合いでギュイーン発生 → 終盤: 集中スローの発動権とギュイーン連勝が試合を決める。ダウン(下段)ごとに仕切り直しが入り、60秒に「章」ができる。

## 7. リスク
- 発生の再遅延でテンポが落ちる → ヒットストップ増と集中スローの「濃さ」で体感速度を補償。プロトタイプで要検証
- 見切りが強すぎ/弱すぎ → 窓±5Fと空振り22Fが第1ツマミ
- 高さタップの誤段 → ゾーン境界に吸着(±20px)と直前段の残像ガイドで補助
- リリース発火の遅延感(+2〜3F) → 全行動の発生に織り込み済み

3. 集中スローは自動発動で良いか（代案: 満タン時に画面長押しで手動発動＝温存駆け引きが増える）
