## 技混成の互換性チェック（初期案）

| 技の種類 | 主要依存 | 代替策／制約 |
|---|---|---|
| 弱/強（拳） | 肩・肘・手首、打撃reachと接触時刻 | 体格ごとにクリップ変換＋実スキン表面の到達距離再測定 |
| 蹴り技 | 股・膝・足、脚長/着地 | 足先高さ/接地と体格差で接触姿勢を再計算 |
| 尾薙ぎ（バレット等） | `tail_01..tail_06`、長尾パーツ、先端軌道 | 長い尾を装備、または別モーション＋別Hitboxに換装。短尾へ6本の回転をそのまま再生しない |
| 飛び道具 | 手/口からの発射ソケット、弾FX、クールダウン | 発射点をアバターの有効ソケットへ補正 |
| 投げ/拘束 | 相手モデルの手位置・サイズ・ペアアクション | マルチリグ同士の被弾/拘束位置へペア演技変換 |
| 当て身・反撃 | 防御姿勢・反撃クリップと固有能力 | 出身技元のスキル状態だけ継承、発動失敗と反撃時の専用反応をテスト |
| 既存奥義約10秒 | 9固有カメラ/表情/双方の骨演技 | 最初の試作は選択スタイルの映画を参照し、アバターは専用の汎用再生演出へ。元9キャラ映画を破壊しない |

### 自キャラ/敵の設計境界
- **見た目 `appearanceId`** と **対戦スタイル `styleId`** を混ぜない。`fighter.id`固定の現行ルールは互換レイヤーへ移し、元9キャラは既存動作を維持。
- スタイルを選んだ後、技カタログに「発生/持続/回復/ガード反撃/コスト/必要骨/必要パーツ/演出FX/状態異常」タグを保存。
- 同じキャラの装飾違いだけで威力が変わる設計にはしない。体格の見た目でreachが変わる場合は対応するHitbox・パワー予算/モーション距離を明示する。
- エディターでの見た目プレビューと、Battleでの技実演と、NPCの3Dマップ表示が同じAvatarFactory構成を参照。
- NPC/モブはseedを保存し全ロードアウトをバリデート。互換外スキル、同時に2体分の固有能力、無限ループなどを除外。

## 承認後の最小試験（技術的な判定表）

- [ ] 骨格3代表体（普通、重量、長尾）でSkinnedMeshを安全に生成。頭/耳/尾の境界に深い穴・二重輪郭がない
- [ ] 本人が自由に指定した2〜5部位色と、少なくとも3模様プリセットが保存/再読込で一致。目/鼻の色まで巻き込まない
- [ ] 装飾（頭帯/スカーフ等）を骨追従させ、待機/通常/被弾/KO/勝利で貫通を検出
- [ ] 選んだ9スタイルのうち少なくとも異なる2スタイルを確認。本人自作アバターが**他スタイルの別技を最低1つ**使い、見た目と判定距離/高さが一致
- [ ] 技の必要骨/尻尾が不足するときに、不自然な透明判定でごまかさず必要パーツ装着か代替アニメを提案
- [ ] 自作キャラ1体が小さな3D広場を前後左右に移動。カメラが自然に追従し、壁/床をすり抜けず、話しかける対象を選べる
- [ ] 既存NPC1体＋seed生成のランダムモブ1体。会話→同一Battleの横画面対戦→勝敗→同じフィールド座標へ帰還、ロードしても結果を保持
- [ ] 既存v15.1の全9体×54通常技、27必殺、9奥義、Practice/KO/アーケード/サバイバル（もし別Issueが先に完了）を壊さない
- [ ] iPhoneの回転ロック/タッチ/音声・メモリ・発熱・GLBロード時間を現行版と比較。端末計測がない限り性能合格とは言わない
