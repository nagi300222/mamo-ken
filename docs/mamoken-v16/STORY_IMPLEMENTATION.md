# v16 集落・エディター・対戦の実装

本人の2026-11-23明示GOに基づく新規実装。PR199 HEAD78dd0c6を基点に、`exp/fable-3d/story/`の独立したThree.js画面として制作した。既存dojoの通常54・必殺27・奥義9・Practiceを置き換えない。mainや既存Draftは未マージ。

## 実装したこと

- 9ベースの選択、頭・耳・尾・手・足の生成器由来形状、装飾の有無、9領域色、4毛模様、名前と9スタイル・3必殺編成を入力。AvatarFactoryで実SkinnedMeshをプレビュー・探索・対戦に共通使用する。
- 小型集落の3D地面、道、4軒の家、樹木、山と灯り。XZの自由移動、壁に沿う衝突処理、後方追従カメラ。キーボードと独立PointerIdのタッチスティック。
- 9既存住人＋seed固定の3カスタム旅人。近い3人まで3Dモデルを読み込み表示し、遠くなったActorを破棄。全員に近づいて会話・キャンセル・稽古を選べる。
- 実スキン後の接触計測を経て同じBattleでCPU対戦する。通常6技・掴み・ギュイーン・方向必殺・咆哮・奥義。ヒット/ガード音、弾と打撃表現、HP・ゲージ・タイマー。
- 実際の`ultimate_hit`だけで既存約10秒映画を再生しBattle/CPU/タイマーを凍結、スキップと復帰。KOは映画が終わってから1度だけ処理する。
- 対戦結果を記録し、戦闘前の探索位置と向きに戻る。キャラ定義・seed・位置・戦績はversion付きローカル保存。壊れた保存は黙って削除せず通知し、新規作成まで残す。
- CSS90度回転によるスマホ横画面UI。OS方向ロックの保証ではない。

## 初期案として採用した制約

- 無制限の体格スライダーや任意メッシュ接合ではなく、9体格と元生成器寸法による境界を保持した形状変更。自由混成は対応確認した技から。
- 互換外の技は理由付きで選べない。体格を変更して以前の技が未対応になった場合、自動で別技へ置き換えず、ユーザーに選び直してもらう。
- 奥義映画中だけは選んだスタイルの元キャラの姿を使う。自作外見のまま全カットを保証するリターゲットは未認証。映画前後の戦闘・探索は同じ自作外見。
- 会話は試運転用の短い稽古の誘い。長編本編・成長や装備のシステムは作っていない。
- KO/勝利映画など#201および連戦#202の画面を複製せず、Storyは独立した開始→対戦→帰還。元道場の制作はroot統合で別ルートとして保持。
