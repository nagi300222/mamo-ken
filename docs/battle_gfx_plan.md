# マモ拳（仮） 戦闘グラフィック移行計画（v0.6）

目的: 戦闘中の図形キャラを卒業し、立ち絵と同系デザインのキャラが GUILTY GEAR 的なキレで動く画面にする。

## 1. 「モーションごとに違うキャラになる」問題への回答
- photorealistic はブレやすい（毛並み・顔の描き込みが毎回変わる）→ **セルルックに変換するとブレが激減**する。GG風の見た目とブレ対策が同じ一手で取れる
- さらに**スプライトシート方式**（同一キャラの複数ポーズを1枚の画像に並べて生成）を使うと、同一画像内生成なので色・体型・装身具がほぼ完全一致する。これが最重要テク
- それでも残る微ブレは「動いている最中は気にならない」（アニメの中割りと同じ）。シルエット・配色・装身具が揃っていれば同一キャラに見える

## 2. 方式比較
| 方式 | 一貫性 | GG感 | 労力 | 判定 |
|---|---|---|---|---|
| **A キーポーズ切替**（1技2〜3枚＋演出乗せ） | ○（シート方式で◎） | ◎（タメ→ドン！のリミテッドアニメ文法） | 中（19枚×3キャラ） | **推奨** |
| B パーツアニメ（立ち絵を分割してボーン駆動） | ◎（絵が1枚） | △（ぬるっと動く。キレは演出頼み） | 小 | 次点・Aの補助に可 |
| C ドット絵 | ○ | ○ | 大（AI生成→手修正の往復） | 非推奨（工程が重い） |

**推奨: A（セルルック×キーポーズ切替）**。GGのキレの正体はポーズ枚数ではなく「キメポーズ＋ヒットストップ＋残像＋エフェクト」で、後者3つは既にプログラム側にある。絵はキーポーズだけでいい。

## 4. 発注手順（一貫性を守る順番）
1. **スタイル変換**: 決定済み立ち絵（moguzo standing）を添付し、セルルックに変換。OKが出るまでここで止まる
```
添付の立ち絵キャラを、デザイン（体型・配色・赤ハチマキ）を一切変えずに
2D格闘ゲームのキャラクタースプライト風へ変換してください。
Style: bold clean lineart, cel-shaded anime coloring like a 2.5D fighting
game, flat colors with 2-step shading, subtle rim light, plain white
background, full body, 3/4 side-facing view.
Keep the EXACT same proportions and head-to-body ratio as the reference
(do not chibify or deform)
```
2. **シート生成**: 変換で決まった絵を毎回添付し、S1から順に
```
Create ONE image containing 4 poses of the SAME character from the attached
reference, in a 2x2 grid. Identical design, colors, scale and lineart style.
Feet aligned on the same ground line, plain white background, cel-shaded 2D
fighting game sprite sheet. Poses: (1)… (2)… (3)… (4)…
```
3. モグゾー15枚が揃ってからピスケ→ゴダン（各キャラもS1から）
4. 切り出し: 2x2を4分割して `assets/chars/{id}/{pose}.png`（透過化）。分割はCodeにスクリプトを書かせてもよい

## 6. 実装方針（Code向け・v0.6として）
- v0.5（ルール・操作改修）は図形キャラのまま先行し、**素材生成と並行**で進める
- v0.6: `SPRITES[charId][poseId]` のレジストリを追加し、rFighter を「ポーズ画像があれば drawImage、無ければ現行の図形描画にフォールバック」へ改修。段階投入可能
- 位置・反転・拡縮・回転・残像・ヒットストップ・集中スローは現行ロジックをそのまま画像に適用
- 足元アンカー基準で描画（シートの接地ライン統一が効く）
- 容量目安: 45枚×WebP512px ≒ 8MB前後。PWA許容内
