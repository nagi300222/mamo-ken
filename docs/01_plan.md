## 1. コンセプト

**移動のない読み合い特化・縦画面マーモット格闘。**
タップとフリックだけで、上中下三段の読み合い → ギュイーン競り合い → 奥義カットイン、まで一気に気持ちよく遊べる。1試合1〜2分。

- タイトル候補: **マモ拳** / ギュイ拳 / MAMO-KEN（以下「マモ拳（仮）」で進行。命名は後でナギ確定）
- 体験の核:
  1. 三段（上/中/下）の攻撃とガードの読み合い（移動なし＝純粋なじゃんけん濃度の高い格闘）
  2. ジャストガード/同段相打ちで発生する「**ギュイーン競り合い**」（マーモットの鳴き声演出＋三択三すくみ）
  3. 競り合いを制した者だけが撃てる**奥義**（パッドが奥義ボタンに変形→暗転カットイン→ガード貫通大ダメージ）

## 2. プラットフォーム / 形態

- スマホブラウザ **縦画面PWA**（v1は完全ローカル・外部通信なし）
- v1スコープ: タイトル → キャラ選択 → **CPU対戦** → リザルト
- 将来（v2+）: オンライン対戦（Cloudflare Workers Durable Objects + WebSocket想定）。そのため**コアロジックは最初から決定論設計**（詳細は要件N-02）

## 3. 画面構成

- 縦 9:16 基準。**上50% = バトルビュー、下50% = 操作パッド**
- バトルビュー（ストリートファイター様式を参照。アセット流用は禁止、様式のみ）:
  - 上端: 左右HPバー + 中央タイマー + ラウンド取得星
  - HPバー下: Sゲージ / ガード耐久ゲージ / 奥義ストック（3段階）
  - 中央: マーモット2体が向かい合う（プレイヤー常に左）
- 操作パッド: 3段×2列の6ゾーン + フリック（詳細は要件F-01）

## 4. コアメカニクス概要（詳細は02/03参照）

| 要素 | 概要 |
|---|---|
| 通常攻撃 A | パッド右列（相手側）タップ。上/中/下の三段。ヒット時のみ最大3連チェーン |
| ガード | パッド左列（自分側）。押下中ホールドで段ガード。段一致で防御成立 |
| S（咆哮） | 相手方向フリック。Sゲージ100消費。全段ガード可だがガード耐久を大きく削る。被コンボ中でも割り込み発動可（バースト） |
| Sゲージ | Aとガードで蓄積。**攻撃側の方が溜まりやすい** |
| 競り合い | ジャストガード or 同段相打ちで発生。ギュイーンSE＋ズーム演出。三択（上/右下/左下）の三すくみで敗者が大ダメージ |
| ガード耐久 | 削り切られるとガードブレイク→気絶（確定反撃チャンス） |
| 奥義 | 競り合い勝利で+1、3つで発動可能。パッドが奥義ボタン化→カットイン→ガード貫通の必中大ダメージ |

- キャラクター: **リアル調モフモフのマーモット × 人間っぽいファイティングポーズ**
