# マモ拳 四足走行 編集済み素材

- `original/`: 受領した原本（無変更）
- `sheets/`: 透明背景・共通セル768×768・横4枚（3072×768）
- `frames/<キャラ>/`: F1〜F4の個別透明PNG（各768×768）
- `EDITING_REPORT.json`: 元寸法、抽出範囲、配置、縮尺

## 採用方針

- 新しい四足走行版ゴダンへ差し替え済みです。
- ダークモグゾーは今回の添付画像を採用扱い。モグゾーからの色変換は行っていません。
- ゴダンを含む全9体を採用候補とします。

## 処理方針

外周とつながったnear-white領域だけを透過し、キャラ内部の白色を保持しました。各フレームは個別抽出後、縦横比を維持して共通セルの下端基準へ配置しています。原本は残しているため、実装時に位置・サイズを再調整できます。
