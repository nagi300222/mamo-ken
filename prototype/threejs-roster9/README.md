# マモ拳 ｜ 山岳道場

Issue #136 の横画面2.5D比較試作。Node.js 24、Python 3、WebGL 2 対応ブラウザを使用する。

```sh
cd prototype/threejs-roster9
npm ci
npm test
npm start
```

ブラウザで `http://127.0.0.1:4173/prototype/threejs-roster9/` を開く。1P と CPU のタブで両者を選んで対戦開始。CPU は待機・後退ガード・対戦を選べる。

| 操作 | キーボード | タッチ |
|---|---|---|
| 移動・ガード | ← →、相手と逆へ入力してガード | ◀ ▶ |
| しゃがみ・ジャンプ | ↓・↑ | ▼・跳 |
| 弱・強（立ち／しゃがみ／空中） | Z・X | 弱・強 |
| 回避・投げ | C・V | 回避・投 |
| 選んだコマンド技 | B、または 1〜7 で直接指定 | 技リスト＋技 |
| 回避の種類 | 前＋回避で踏み込み、後＋回避でスウェー、下＋回避でしゃがみ回避、方向なしで見切り | 方向を押しながら回避 |

「操作・判定」から一時停止、1F送り、¼速、攻撃リーチ倍率を設定できる。水色はやられ判定、黄は押し合い、赤は有効中の攻撃、足元の点は描画原点。「初期値に戻す」で判定倍率・速度・ラウンドをリセットする。

能力と映像の比較条件は [ADAPTATIONS.md](ADAPTATIONS.md)、技と素材の棚卸しは [SOURCE_AUDIT.md](SOURCE_AUDIT.md)。レビュー画像は [review](review/)。
