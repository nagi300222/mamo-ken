# マモ拳 v0.13｜必殺技は通常対戦で派手、奥義は命中時だけムービーへ

本人の新要件：**「演出的には奥義ぐらいのものを必殺技に、奥義はヒットしたらムービーに移行するイメージ」**。

## 仕様と今回の試作

- 必殺（s1/s2/s3）は旧v0.11奥義と同じレベルのカットイン、キャラ別エフェクト、軌跡、衝撃・音を通常画面で発動。試合進行は停止しない。
- 奥義ボタン押下だけではムービーにならない。発動予兆は短い。必ず `battle.events[].type === 'ultimate_hit'` のイベントを通してゲーム状態の命中/非ガード・HPダメージを確認してから移行。
- ヒット時は、既存のWebGL canvasをフルスクリーンのシネマティック枠へ一時移動。**追加WebGLレンダラ・動画ダウンロードは不要**。同じ2体のGLBと既存アニメを、映画的なカメラカット・キャラ固有セリフ帯・衝撃リングで描く。
- 最初のバージョンは**リアルタイム3Dインエンジンの短いシネマティック**であり、事前に作り込まれたMP4動画ではない。後から9体別に専用シーン/動画/独立モーションを導入するための演出土台。
- 演出中はCPU・戦闘入力・戦闘フレーム・ラウンドタイマーを停止。既存のDamage/Guard/HP/Drive/Super/KO計算の変更はなし（追加するbattle.jsの変更は**表示通知イベントだけ**）。
- そのまま継続できるヒットの場合は同じ試合へ復帰。KOならムービー後に勝敗パネルを出す。ユーザーはムービーをスキップできる。
- `prefers-reduced-motion`は短いシネマティックで対応。ボタン操作やレール、通常カメラを改変しない。

## 受け入れ
- [ ] 必殺技が見た目と音で以前の奥義レベルになっている。
- [ ] ムービーは**奥義命中だけ**（空振り／ガード／見切り返し／阻止では移行しない）。
- [ ] 命中で全画面切替・キャラ別演出・2秒前後のカメラカット。iPhone横画面で画角を確認。
- [ ] ムービーでHPとゲージが二重減算されない、タイマーが止まる。
- [ ] KOでもムービー後リザルト。スキップ後に入力・カメラ・canvasが戻る。
- [ ] ノードテスト、Pages build、Chromium実GLB、スマホ実機負荷。
- [ ] main/元GLB/バランスv0.5/操作v0.7はそのままDraftを保全。
