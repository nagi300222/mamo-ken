# マモ拳3D v0.7｜スマホ向け「方向＋必殺」「奥義専用ボタン」操作PoC

> 本人希望に基づく試作（技割当や右6ボタンの最終採用判断はスマホ実機試遊後）。旧v0.6ステップ・v0.5 CPU/9体バランスと承認済みv0.3カメラを維持。

| スティック＋ボタン | 新しい入力（プレイヤー） | 対応する現行技 |
| --- | --- | --- |
| 必殺 | ニュートラル（後ろ方向も含む）＋必殺 | s1 / 236系 |
| ↑＋必殺 | 対空・上方向 | s2 / 623系 |
| →＋必殺 | 相手方向（左右は自動反転） | s3 / 214系 |
| ↓＋必殺 | 下方向を最優先（斜め下を含む） | 共通咆哮 |
| 奥義 | 専用ボタン（ゲージ100のみ） | ultimate / 236236系 |

- 右ボタン6つ＝弱・強・掴み・ギュイーン・必殺・奥義。従来の独立咆哮ボタンは画面上から外す。
- 左のスティックと前後ステップ2ボタンは維持。
- `special`/`ultimateButton` は新しい入力エッジ。CPUの `special1..3`/`super`、従来の236/623/214/236236＋弱強の認識は比較用に残す。技の性能値を変更しない。
- `↓+必殺` は咆哮の既存Drive消費／CD／返し・弾消しをそのまま使う。特殊技が使えるのに「咆哮のDrive不足」を理由に必殺ボタン全体を無効表示しない。
- 特殊入力は同一フレームの通常移動・ジャンプより優先。奥義ボタンと必殺の同時押しは奥義優先。奥義ゲージが足りないとき、通常技には化けない。
- PCではZ弱／X強／V掴み／Nギュイーン／B必殺／M奥義。F/Rステップ。
- ゲーム内のFPS・判定・モーション・カメラ・GLBは不変。UIのレール幅・中央キャンバス幅を固定したまま右3×2配置を試す。
