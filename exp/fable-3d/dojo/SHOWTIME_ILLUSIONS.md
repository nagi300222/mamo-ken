# ヨル制作レーン｜チルカの実3D分身 (v0.9)

## 実装目的
本人発案の「チルカの奥義で分身する」を、既存マモ拳3D GLBそのものから描く。前段のリングだけの疑似分身から一段進める。**対戦中の追加キャラ・判定・ダメージは一切存在しない。**

## 実装
- `three/addons/utils/SkeletonUtils.js` の `clone` でチルカの既存GLBから**実際の2体のスキン付きモデル**を生成。通常ゲームキャラの骨格とアニメーションに干渉しない。
- `super` の同名アニメーションを幻影側でも再生、薄紫の半透明素材と両側への移動（最大28 simulation frames）、消えるときは非表示。
- メッシュジオメトリとテクスチャは共有するが、半透明設定用に複製したMaterialだけ所有して解放する。ゲーム内のGLBは書き換えない。
- reduced motionが設定されているときは分身を作成しない。
- 画面位置やゲームロジックを変えず、renderer同期後の見た目だけ。

## 受け入れ
- [ ] チルカの奥義でアニメーションした薄紫の**3D分身が2体**見えること。
- [ ] ゲーム内の追尾カメラ・ヒット判定・ダメージ・CPU・6ボタン操作は不変。
- [ ] 技をキャンセル/KO・再戦したあと残像が残らないこと。
- [ ] iPhoneでFPS/描画乱れを確認する。
- [ ] Node回帰・Pages build / Cloudflareブランチプレビューを確認してから本人が採否を決める。

> ここで作ったコードはミオの先行実装。ヨル（Claude）が実際に独立レビューや元GLBの専用モーション調整を行ったとはまだ言えない。
