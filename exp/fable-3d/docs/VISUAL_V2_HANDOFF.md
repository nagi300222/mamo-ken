# Visual v2｜3D造形改善の制作ハンドオフ
**状態：未制作の改善計画（Claude向け）。** 現行全9キャラの初版GLBは [Draft PR #141](https://github.com/nagi300222/mamo-ken/pull/141) に存在。ゲーム試作は [Draft PR #143](https://github.com/nagi300222/mamo-ken/pull/143) の独立レーン。

## 今回の受け入れ条件
- 3DモデルのID、足元原点、`idle`/前後歩行/`dash_f`/`crouch`/`jump_n`/`stand_light`/`stand_heavy`/`guard_stand`/`hurt_light` と固有クリップ名を維持。
- 新作格ゲーのスマホ横画面で、キャラ選択原画と**顔の向き・輪郭・毛束**が似ていること。単なる色違いの球体顔にしない。
- モデルの見た目と戦闘仕様を分離し、`dojo/models.js` が参照するGLBパスだけを更新すればゲームに反映できる構成を維持。
- バレットの尾の長さ/骨格を変更したときは、`bullet_motions.json` の `tail_tip_path` を再測定。新旧リーチ比較を提示し、対戦の判定用データへ伝える。
- 造形の新旧比較・変形確認・90共通クリップ回帰、9固有クリップ、コンソールエラーの有無を報告。「検証成功＝元絵合格」とは扱わない。

## 共通修正の優先度
1. 目の輪郭・まぶた・眉（頭部へのめり込みとスキニングを防ぐ）とマズル/口の立体的な形を調整。
2. ヒゲと頬・肩・腹の輪郭の毛束。スマホで見える大きめの毛束と、細かなテクスチャによる表現を使い分ける。
3. 構え/蹴り/しゃがみでの太ももの外側の膨張を緩和（股関節の位置・`thigh_fix`・ウェイト）。
4. 拳の親指と爪、開き手と握り手のつながり。

## 個別に見ること
- `moguzo`：洋梨形のシルエット、突き出たマズル、ハチマキの厚み
- `pisuke`：小さめの頭と前へ出た鼻先、細身の脚、青リストバンド、蹴り時の体積維持
- `godan`：鋭い怒り眉、肩から首の立体毛束、重量感と黒帯
- `hakuma`：顔のマスク、ゆったり重なったスカーフ、腹の厚み
- `chirka`：つり目・ずる賢い目つき、濃色の頭頂、紫の房
- `takimaru`：ねじり縄の立体感・接地と体追従、開き手の爪
- `yomikage`：半身構え、包帯の巻き目、毛の長さの差
- `bullet`：長尾の先細りと毛束、尾薙ぎの伸展と戻り、木の玉
- `dark_moguzo`：主人公と共通体型を維持しつつ、険しい眉・濃色ハチマキの差

## 作業対象と仕分け
SDF/パラメータの共通形状 `tools/mamo3d/characters.py`、付属部品 `body.py`、テクスチャ `texture.py`、必要な姿勢補正のみ `motions.py`。造形を変えたら`build_all.py`と`validate.mjs`を実行し、新旧比較を保存。実データ編集と再生成・撮影はこのブランチで行う。ゲームの`battle.js`や`balance.js`は編集しない。

**注意：この文書だけではGLBは変更されない。Claudeが実際にコードを修正・生成し、差分をレビューしてから完了扱い。**
