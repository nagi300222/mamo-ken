# 参照画像の分析（moguzo / pisuke / godan）

参照したのは `assets/portraits/{id}.png` と `assets/roster3d/{id}.webp` のみ。
旧ピクセルアート、`assets/chars` の戦闘スプライト、他ブランチ・他AIの試作は開いていない。

測定は portraits のアルファ輪郭を行ごとに走査した値（幅÷画像高さ）と目視による。
portraits は斜め前からの一枚絵で、構えで膝を曲げているため、数値は「絵の中の見かけ」であり正面正射影の実寸ではない。

## 共通して読み取れること

- 画風は「粘土フィギュア調」。毛は一本ずつではなく、下向きに重なる葉っぱ形の毛束が彫られている。
  毛束の谷が暗く、先端が明るい。godan が最も彫りが深く、pisuke が最も細かく柔らかい。
- 首はほぼ見えず、頭から肩へなだらかにつながる。頭は体に対して大きい（全高の約3割）。
- 目は黒い光沢のある球で、白いハイライトが1点。白目は見えない。目の間隔が広く、顔の側面寄りにつく。
- 鼻は濃い色の逆三角形で、鼻の下から短い縦線、そこから左右に下がる口の線。マズルと頬は体より明るい。
- 耳は小さな半円で、頭頂の左右やや後ろ。内側が少し暗い。
- 腕は太く短く、肘を曲げて拳を胸の前に構える。手の甲が外、指が内側（体側）を向く。
- 脚は短く、太ももは胴の毛に埋もれて「洋梨形の下半身」に見える。足は平たく、指は4本、黒い爪。
- 尻尾は短く太い。毛束でぼさっとしている。構えでは体の後ろ下に少しだけ見える。
- roster3d は portraits とほぼ同じ絵の縮小版で、追加の角度情報は無い（背面・側面は推定で作る必要がある）。

## moguzo

| 項目 | 観察 |
|---|---|
| 体格 | 標準。洋梨形で、肩が狭く腰が広い。輪郭幅は頭 0.32〜0.34H、胸（腕込み）0.50〜0.58H、腰 0.63〜0.67H |
| 毛並み | 黄土色〜薄茶。胸から腹は広くクリーム色で、境界は毛束でぼかされる。背・腕の外側・腰の側面がやや濃い |
| 顔 | 丸く大きな黒目。鼻は濃い灰茶。マズルと頬〜あごがクリーム色。口は軽いへの字。眉は無く、穏やかだが真剣 |
| 装飾 | 赤いハチマキ。額の中ほどを通り耳の前〜下を回る。結び目と垂れ2本は本人の右側頭部（画像では左） |
| 拳 | 焦げ茶でつやのある握り拳。指の節が3〜4本見える。手首から前腕にかけて毛色へグラデーション |
| 足 | 濃い灰色で平たい。指4本に黒い爪。つま先は外向きに約20度 |
| 尻尾 | 短く、本人の右後ろに少し見える。体毛と同色 |

事前メモとの差分：メモ通り。追加点として「胸のクリーム色は頬・マズルまでつながっている」「足は指の付け根まで灰色」。

## pisuke

| 項目 | 観察 |
|---|---|
| 体格 | 細身で縦に長い。頭は小さめ（幅 0.27〜0.29H）、首から肩がなで肩で、胴がくびれる（胸下 0.41H）。腰は 0.62H まで広がるが、これは足を前後に開いた構えの分を含む |
| 毛並み | 明るい砂色でほぼ単色。腹がわずかに明るい程度で、moguzo のようなはっきりした色分けは無い。毛束は細かく柔らかい |
| 顔 | 頭頂が平たく、マズルが前に長い。目は moguzo より少し小さく、やや上がり気味。鼻は小さく黒い。ヒゲがはっきり見える。口角が少し上がる |
| 装飾 | 両手首に青いリストバンド（厚みのある布の筒） |
| 拳 | 体毛とほぼ同じ明るいクリーム色。指の間に黒い爪が見える。握りは軽い |
| 足 | 明るいクリーム色で細長い。黒い爪。前後に大きく開き、前足のかかとが少し浮く |
| 尻尾 | 短めだが moguzo より後ろへ突き出して見える |

事前メモとの差分：メモ通り。追加点として「頭が体に対して小さい」「マズルが長い」「足も明るい色」。

## godan

| 項目 | 観察 |
|---|---|
| 体格 | 幅広の重量級。肩と腕が大きく張り出し（腕込みで 0.83〜0.87H）、帯の位置で一度締まり（0.55H）、腰から脚でまた広がる（0.88〜0.95H）。頭は体に対して小さく見える（0.30H）。首は肩の毛に完全に埋もれる |
| 毛並み | 濃い茶色。胸〜腹は明るい黄土茶で、毛束の彫りが3体で最も深い。肩と前腕の毛束が外へ逆立つ |
| 顔 | 怒り眉。目の上に明るい色の眉の盛り上がりがあり、内側へ強く下がる。目は小さめで鋭い。マズルは明るい黄土色で四角く、口は強いへの字。鼻は大きく黒い |
| 装飾 | 黒帯。正面に結び目、垂れ2本が斜め下へ。両手首に黒いリストバンド（革っぽく薄い） |
| 拳 | 非常に大きい焦げ茶の拳。指の節が4本、角ばっている |
| 足 | 濃い焦げ茶。大きく開いて外を向く。爪は灰色がかった黒 |
| 尻尾 | 本人の右後ろに少し見える。濃い茶 |

事前メモとの差分：メモ通り。追加点として「眉は毛の色ではなく明るい盛り上がり」「マズルが四角い」。

## 身長比（仮）

元絵には3体を並べた基準が無いので、次を仮の比較値として置く。roster3d の拡大率は使っていない。

| キャラ | 仮の全高（耳を除く頭頂まで、直立のレスト姿勢） | 根拠 |
|---|---|---|
| moguzo | 0.60 | 基準 |
| pisuke | 0.63 | 細身で縦長の印象を出すため少し高く |
| godan | 0.66 | 重量級。高さより幅で差をつける |

単位は Blender のメートル扱いだが、ゲーム側では任意に拡大してよい。値は `tools/mamo3d/characters.py` の `height` で変えられる。

## 3Dにするとき推定で補った部分

- 背面・側面の形と色（背中は体毛の濃い側の色で統一、腹の明色は背中へ回らない）
- 脚の骨格（太もも・すね・足首は絵ではほぼ毛に埋もれている）
- 尻尾の全長
- pisuke の反対側の腕、godan の帯の背面（結び目は正面のみと仮定）
