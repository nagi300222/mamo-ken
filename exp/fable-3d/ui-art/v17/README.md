## 作りの約束
- **すべてオリジナル**。外部の画像・フォント・他作品の UI は使っていません。文字は 1 つも焼き込んでいません（名前や数字は DOM で重ねる前提）。
- **色は CSS 変数で差し替え**：`--mk-bg` `--mk-panel` `--mk-text` `--mk-action` … を親要素に置くと素材の色が変わります。キャラ識別紋は `--mk-char`、ボタン台の縁は `--mk-button`、単色の拳紋は `currentColor`。
  （`<img>` で読むと変数は届かないので、色を変えるときはインライン SVG にします。変数なしでも `tokens.json` の初期値で描かれます）
- **色だけに意味を持たせない**：5 モード記号は形で区別（拳／登る稜線と旗／焚き火／足あとの道／稽古柱）。9 キャラ識別紋は枠の形（丸・ひし形・八角・雪の結晶・瞳・二重の輪・三日月・長円・逆三角）と中の図が全員違います。
- **全員マーモット**：印章と紋の拳は、指の節と肉球のある前足の握り拳です。
- 木札・紙・布・斜め切りパネルは 9 スライスで伸ばせます（余白は `manifest.json` の `slice`）。

## 2 つの方向（構図ごと違う案）
- **A「山の格闘大会」**（対戦・モード選択・キャラ選択）：斜めに切った大きな面、稜線の重なり、木札、朱の印章。主役の「戦う」を最大に。
- **B「旅の稽古帖」**（キャラクリ・探索）：紙の帳面、札の重なりで手順を見せる。探索は景色を主役に、札 1 枚と移動・会話だけ。
