# v16 modular avatar production

User implementation approval: 2026-11-23, Issue #203. Baseline: PR #199 `78dd0c6`. This is the appearance production lane; the original nine GLBs, 54 normal clips, 27 specials and nine movies are not edited.

## Actual assets and authoring

`tools/build_avatar_assets.py` imports the original `tools/mamo3d/characters.py` and SDF primitives. It reads each original GLB and partitions the complete triangle set into **body, head, ears, hands/arms, feet/legs, tail and accessory** primitives. Shared seam positions, bind matrices, morph targets and all original 37 animations are retained. New vertex semantic attributes provide region colors and shape selection. Modules are compacted to avoid retaining seven full vertex buffers per actor. Assets are in `assets/*_parts.glb`; the manifest records SHA256, source SHA256, counts, palettes and generator dimensions.

Rebuild from the repository root:

```sh
python exp/fable-3d/custom/v16/tools/build_avatar_assets.py
```

Dependencies: Python 3 + numpy only. The installed Blender 4.3.2 successfully imports the source GLB. The original compressed `.blend` is Blender 5 format and cannot be opened in 4.3, so it is preserved and **not** overwritten or misrepresented as newly edited Blender data.

## Runtime contract

`createAvatar(definition, {loader?})` returns `{scene, animations, bones, meshes, baseId, appearance, parameters, grafts, gltf, dispose}`. It combines the original 37 clips with the six v15 normal clips and uses the same original skeleton. The normal pack must be generated by the existing Pages build.

Input is `definition.appearance = {baseId, parts, palette, pattern}`. Exported `AVATAR_PARTS`, `AVATAR_PATTERNS` and `AVATAR_PALETTE_KEYS` drive the editor. Colors include fur, belly, muzzle, paws, feet, ears, tail and accessory, plus pattern color. Protected eye/shine/nose/claw regions retain their texture colors. Pattern choices are solid, spots, stripes and eye mask. Each avatar clones materials/geometries and disposes only those owned resources; cached textures remain shared.

Part choices change the selected **region geometry using the donor base generator's dimensions**. They are parameterized shape grafts, retaining base topology, bone lengths and seams. They are **not arbitrary donor remesh replacement** or unlimited body sliders. Head, ear, paw, foot and compatible tail shape choices are implemented. Tail choices must have the same tail bone count (Bullet's six-bone long tail cannot be attached to a three-bone base). Accessories support base/none; cross-character accessory rig attachment remains unsupported and must be disabled with a reason in the UI. Arbitrary full donor heads, donor finger topology, long-tail skeleton conversion and interchangeable cloth rigs remain later production work.

`measureContacts(avatar)` samples the actual post-graft skinned mesh at all six normals' three active times. It returns `{normals, hurtBounds, projectileSocket, source:'runtime-skinned-mesh'}`. Normals use the appearance rig's real surface, independent from the chosen combat style. Hurt bounds sample standing/crouched holds separately; the standing entry frame is excluded from crouch bounds. `measureProjectileSocket(avatar, retargetedClip, contactSeconds)` measures the actual paw socket at the equipped projectile's firing time. Unsupported melee mixing needs its own measurement/compatibility gate in the combat lane.

## Verification

```sh
node --test exp/fable-3d/custom/v16/avatar-assets.test.mjs
node --experimental-loader ./exp/fable-3d/custom/v16/tools/three-loader.mjs \
  exp/fable-3d/custom/v16/tools/verify-avatar-cpu.mjs
```

The asset test checks all nine hashes, source preservation, skin/animation equality, all seven modules, total triangle conservation and compact attributes/morph targets. CPU verification uses the actual vendored GLTFLoader, AnimationMixer and `SkinnedMesh.getVertexPosition`, plus original six-normal packs. Node image stubs only avoid decoding JPEGs for CPU sampling: **this is not evidence of texture/shader rendering or smartphone performance**. Integration evidence was produced separately on 2026-11-23: [run 45111784490](https://github.com/nagi300222/mamo-ken/actions/runs/45111784490), tested integration HEAD `57b140b6`, avatar/custom/story/core lanes all successful. Chrome/SwiftShader rendered six original/grafted avatars with their real textures/shaders; screenshots were inspected for silhouette, protected eyes/nose, region colors and patterns. The same runtime measured 54 normal contact boundaries and 54 cross-rig projectile hits, and Story's morph-driven Chirka attacks in both directions. Browser artifacts include PNGs and JSON. This is software-rendered WebGL, not an iPhone performance or full seam/art sign-off. No physical-device FPS/temperature claim is made.
