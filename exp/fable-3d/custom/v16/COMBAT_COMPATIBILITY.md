# v16 カスタム対戦：初期実装と互換性

本人の実装承認: 2026-11-23、Issue #203。基準: v15.1 Draft PR #199 / `78dd0c6`。これは技の無制限混成の完成認証ではない。

## 実装

`avatar-schema.js` は外見 `appearance.baseId/parts/palette/pattern` と、戦闘 `combat.styleId/specials` を分離する。9骨格と9スタイルの組み合わせが可能。保存データを検証し、未知の骨格・技・パーツ・保存形式、誤ったカラー値を拒否する。既存9体の初期色は元の `mamo3d/characters.py` 由来。名前は1〜24文字。

`custom-combat.js` は新しい戦闘エンジンを作らず既存 `Battle` を使う。`fighter.id` は選択スタイル、`visualRigId` は外見骨格、`definition` は保存可能な定義。HP・移動・能力・通常技の発生/持続/硬直・ダメージはスタイルに従い、通常技の姿勢・到達距離・高さは外見の実スキン表面から得る。発生時刻へ対応する外見のアニメ接触姿勢を再生する。

Battleへ加えたのは任意の移動作解決・被弾高さ・飛び道具射出位置/高さ接触と再戦のアダプターだけ。アダプターを渡さない既存9キャラ対戦は以前の経路を使う。性能表・原モデル・既存の27必殺/9奥義は変更しない。

## 初期の対応技

| 技 | 対応条件 |
| --- | --- |
| 6通常技 | 外見骨格の6専用モーション。形を変えた場合はアバターの実スキン接触計測を必須とする |
| 6種の基本飛び道具 | モグゾー/ピスケ/タキマル/ヨミカゲ/バレット/ダークモグゾーの `s1`。3スロットのどこにも装備可能 |
| 外見骨格本来の打撃必殺 | 外見骨格と技元が同じ、手足が元の形であること。手足交換後の必殺接触計測は未対応 |
| バレットの尾技 | バレット骨格と元の6ボーン長尾が必要。短尾骨格へ透明な長尾判定を移植しない |
| ヨミカゲの当て身 | 外見骨格に加え、見切り能力を持つヨミカゲスタイルが必要 |
| 他の骨格の打撃/投げ | 初期版では未対応。技一覧へ理由を示し、勝手に別の技へ変更しない |
| 奥義 | 選択スタイルの既存映画を参照。初期Storyでは映画中に元のスタイルの姿へ切り替える設計上の制約を表示する |

混成技の発生・硬直・威力・弾速・寿命は出身技の値を保つ。選択スタイルの固有能力だけがBattle内で働き、技の出身者の能力を追加しない。技の出身アニメを実際に読み込み、`custom-animation.js` で元と移植先のレスト位置・回転差分を補正する。頭/体幹/手足などの必須ボーンが不足すれば拒否する。飛び道具では使わない装飾骨や追加尾骨だけを明示的に省く。ボディ全体の単純な拡大や、同じ動作への技名の付け替えは行わない。

`measureContacts(avatar)` の結果 `{normals,hurtBounds,projectileSocket,source:'runtime-skinned-mesh'}` を `createCustomBattle(...,{measurements:[player,opponent]})` へ渡す。形状変更時に計測なしで進むことは禁止。色・模様のみで形が変わらない場合はv15.1の元表面計測値を利用できる。技別の発射ソケットを測った場合は `measurement.projectileSockets[ref]` を単一ソケットより優先する。


初稿では新規9テスト、既存134テストが合格。新規試験には、81通りの外見/スタイルでの通常技解決、6飛び道具×9体の実Battleヒットと単発ダメージ、元GLBから読み取った54通りの移植先必須ボーン・有限キー・元アニメ不変、1000seedのモブ再現、長尾/当て身/未計測形状の拒否、計測データによる実当たり判定、再戦時のカスタム保持が含まれる。
